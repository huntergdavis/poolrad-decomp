# Unit 1C Up script-entry boundary

`pr_u1c_script_start` and `pr_u1c_script_resume` extend the [window/key dispatch](U1C_UP_DISPATCH_SHARED_BUS.md) on the same bus and CPU when it reaches `+344C`. Standalone `pr_u1c_script_entry` begins there and reads live `DS:49FF`. If zero, it pushes the live `DS:49E3` word and CS, validates the reached near call at `+3458`, pushes its real return `+345B` and stops at `+3171` before executing the script runner. If the gate is nonzero, the source rereads `DS:442F` and, where reached, `DS:49FF`, stopping at `+3462`, `+34F5`, or `+3473`. Earlier dispatch outcomes `+33EC` and `+33E6` remain separate `OTHER` boundaries; a U68 zero-movement result remains the prompt-loop boundary. No script body or dispatcher effects are fabricated.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. `[344C,3473)` is 39 bytes, SHA-256 `0059a9926232d0e257333772449905f5ee1afea19c3002e2a662279bf093c7fe`. The earlier [U1C loop audit](U1C_LOOP_3387.md) and [3171 runner audit](U1C_ECL_RUN_3171.md) identified the call and gates; this span was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `344C`, `BP>=8`, `SP=BP-2`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The caller supplies real code and bindings, immutable code outside EGA, writes that avoid code, nonwrapping reached return frames and the earlier provider profiles. A malformed near call stops at `+3458` after the source argument and CS pushes. The composed session inherits the checked 1C target and previous U68/clear/printer profiles. This is a bounded profile, not a general alias or hardware proof.
