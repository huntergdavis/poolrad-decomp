# U68 to 290B record branch

`pr_u68_290b_branch_start` and `pr_u68_290b_branch_resume` extend the existing [two-field path](RES_290B_TWO_FIELDS.md) on the same bus and CPU to `00BA:2A51`. Standalone `pr_290b_record_branch` begins at `+2A02`. It reloads the live `DS:[49D2]` far pointer, compares the word at record `+01F6` to zero and preserves the 16-bit comparison flags. Nonzero jumps directly to `+2A51`; zero formats the two live local bytes through guarded `1037`, concatenates the caller-owned `CS:28F4` and `CS:28F6` strings with the real `0B98` leaf, and stores the result through `0B25`. Reached call bytes and return frames are checked, and nested stops retain earlier effects. No game bytes or literals are embedded.

The pinned START.EXE SHA-256 is `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`; the 79-byte loader-expanded `00BA:[2A02,2A51)` span hashes to `94ceda58d566f9006ded7302c5847a032100bf546a84bc3d47a4a74c75c2f318`. The earlier [290B source audit](RESIDENT_ROUTE_290B.md) and [1037 CPU audit](SYSTEM_STR_1366_RES_1037.md) were reused; the branch instructions were decoded against the pinned executable.

The standalone entry requires the existing live 290B frame (`BP` in `[043C,FFEE]`, `SP=BP-0232h`), exactly 1 MiB RAM, an EGA bus, and ordinary CS, DS and SS windows below `9000` or at least `B000`. Effective record word offset `FFFF` stops before the read at `+2A06`. The guarded byte formatter uses the verified flat-RAM `1037` instruction model with the same bounded entry and reached-call aperture guards as [1073](RES_00BA_WORD_STRING_1073.md): SP `[0200,FFF0]`, ordinary caller CS and SS; with EGA attached, nested Str's live CS and StrStore's live CS and destination must be ordinary. This is a conservative profile, not general EGA support for those leaves. Caller-owned code, relocations, literals and earlier frame contents remain required.

Synthetic tests cover byte truncation, formatter call/profile/callee stops and stack overlap; idle-to-Up through both fields and the zero branch; nonzero branch flags and EGA read/latches; malformed second formatter call; and record word-wrap stopping. The fixture and wrapper passed strict-warning ASan/UBSan linked to the existing provider archive. They do not establish original-runtime or native differential parity. `+2A51` precedes further string assembly, display and U68 return; no full display, gameplay or coverage credit is claimed.
