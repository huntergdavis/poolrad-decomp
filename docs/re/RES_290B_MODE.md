# U68 to 290B mode branch

`pr_u68_290b_mode_start` and `pr_u68_290b_mode_resume` extend the [assembly path](RES_290B_ASSEMBLY.md) on the same bus and CPU to `00BA:2B36`. Standalone `pr_290b_mode` begins at `+2ACD`. Mode byte `DS:49F3` equal to 2 appends the caller-owned `CS:28FA` literal. Other values reload `DS:[49D6]` and read the live record word at `+0594`: a clear low bit skips the append and a set low bit appends caller-owned `CS:2903`. Appends use the real guarded `0B0B`, `0B98`, and `0B25` leaves. Reached call checks, live return frames and partial effects are retained.

Pinned START.EXE SHA-256 is `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`; loader-expanded `00BA:[2ACD,2B36)` is 105 bytes, SHA-256 `4117c5058a0076dc06442f3700e06d65d85eff431d3714f4c0a7b108c0602e5c`. The earlier [290B audit](RESIDENT_ROUTE_290B.md) identified the branch and calls; the span was independently decoded against the pinned executable. No game bytes or literals are embedded.

Standalone entry requires the existing 290B frame (`BP` in `[043C,FFEE]`, `SP=BP-0232h`), exactly 1 MiB RAM, EGA attached and ordinary CS/DS/SS windows below `9000` or at least `B000`. An effective record word offset `FFFF` stops before the read at `+2B02`. Record words use the shared bus and retain EGA latches. Logical flags use the project's pinned normal/386 convention: CF, OF and AF clear, ZF/SF/PF from the result. Each flat string call checks its live segments using the existing bounded profile; caller-owned code, relocations, literals and prior locals remain required.

Synthetic tests cover idle-to-Up, mode 2, clear and set record flags, EGA word read and latches, word-wrap and malformed-call partial stops, invalid frames and suspended CPU tampering. The wrapper and fixture passed strict-warning ASan/UBSan linked to the existing provider archive. These are not original-runtime or native differential tests. `+2B36` precedes the display call and U68 return; no full display, gameplay or coverage credit is claimed.
