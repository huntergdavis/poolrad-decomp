# OVL_0025 +06D3 and +06FB: shared raw entries for the text-code remap and the address classifier (carved out; no new credit)

`OVL_0025_06D3` and `OVL_0025_06FB` are **already strict**. Their credits rest on the semantic `pr_rec_ecl_char_remap` and
`pr_rec_ecl_address_class` ([ECL_HELPERS_ORIGINAL_AUDIT.md](ECL_HELPERS_ORIGINAL_AUDIT.md)). This change gives each body
a **raw full-state entry** that the hybrid dispatch can call. **No credit or ledger change** is proposed. The new audit
is added to both rows' evidence.

**Pre-claim grep (widened per PM i22089), `(\+|0x|:)06D3\b` and `06FB`.**
- **`+06D3`** has a full-state translation, `body_06d3`, inside the credited `overlay_u25_string_cores.c`. `+1153` calls
  it twice and `+12FB` once.
- **`+06FB`** has four:
  - `body_06fb` in `overlay_u25_string_cores.c`, called by `+12FB`;
  - `classify()` in `overlay_u25_store_string_0f53.c:209`;
  - `classify()` in `overlay_u25_store_word_0c77.c:140`;
  - `classify()` in `overlay_u25_load_word_0e0c.c:154`.

**The carve-out.** As the PM ruled (i22463), this is a carve-out, **not a second copy**. The two new public functions are
defined in `overlay_u25_string_cores.c` itself:
- `pr_u25_char_remap_06d3_cpu` (`overlay_u25_char_remap_06d3_cpu.h`);
- `pr_u25_address_class_06fb_cpu` (`overlay_u25_address_class_06fb_cpu.h`).

Each one runs the **unchanged** static body that `+1153` and `+12FB` call, on a copy of the caller's 14 words. One
implementation therefore serves the hosts, the dispatch and the audit. Keeping the entries in that file also means none
of the 12 audits and 4 CMake test targets that compile it needs a new source.

**Not now (PM i22463):** the three other `+06FB` copies in `0F53`, `0C77` and `0E0C` stay as they are. They are named
here as duplicates, and "consolidate the 06FB copies" is on the PM's standby list.

Both are leaves with no fixup and no public entry. Callers use `PUSH CS; CALL near` with one argument word.

## What the bodies do

**`+06D3`:**
1. `PUSH BP; MOV BP,SP; SUB SP,2; CMP BYTE [BP+6],1Fh; JBE`.
2. A code above 1Fh is kept (AH kept). Otherwise `MOV AL,code; XOR AH,AH; ADD AX,40h`.
3. The byte goes through `[BP-1]` to AL, then `RETF 2`.

Flags at the RETF: ADD's, or CMP's on the kept path. XOR's flags are overwritten by ADD's.

**`+06FB`:**
1. `[BP-1] := 4`.
2. For the ranges 4900–4CFF, 6B00–6EFF, 9700–98FF and 9900–B6FF in turn: `CMP lo; JB next; CMP hi; JA next; [BP-1] :=
   0, 1, 2 or 3`.
3. `AL := [BP-1]; RETF 2`.

The last CMP executed reaches the RETF.

**Contract** (both entries):
- statuses RETURNED, ARGUMENT and TRANSFER;
- exactly 1 MiB of A20-off RAM;
- entry SP in `[0004h,FFFAh]`;
- every operand reread from RAM;
- the FULL pinned flags.

## Checks

`tools/overlay/u25_06d3_06fb_cpu_audit.py` (CHECKER_ROWS `OVL_0025_06D3`, `OVL_0025_06FB`) runs the original bytes in
Unicorn. It compares the 14 CPU words, all 1,048,576 RAM bytes and the stop, **with no flag masks**.

**Unicorn: 630 cases, every one equal and RETURNED. 630 independent statements.** The cases are:
- all 256 code bytes, each with a random high byte;
- every range edge ±1;
- six entry FLAGS values;
- the SP edges and an A20 stack wrap;
- 300 random states.

| | `+06D3` | `+06FB` |
| --- | --- | --- |
| Instruction starts reached | 16 / 16 | 28 / 28 |
| Conditional outcomes | 2 / 2 | 16 / 16 |

**Mutants: 12, applied to the static bodies the hosts also run. Eleven are caught by the differential.**

| Mutant | Result |
| --- | --- |
| 06D3: JBE read as JB | caught |
| 06D3: CMP against 20h | caught |
| 06D3: ADD 41h | caught |
| 06D3: XOR AH,AH missing | caught |
| **06D3: ADD as a byte add** | **survives, and is equivalent**: AH is 0 and the sum is at most 5Fh, so the byte and word flags coincide |
| 06FB: default class 5 | caught |
| 06FB: first JA read as JAE | caught |

| 06FB: RETF 2 pops 0 | caught |

**C test:** `tests/recovered/test_overlay_u25_06d3_06fb_cpu.c`, built with ASan/UBSan and asserts on. It covers:
- the remap at 00h, 1Fh, 20h and FFh, with hand-derived flags;
- every class, with the flags at 4900h, B6FFh and C000h;
- the SP edges;
- atomic ARGUMENT for both entries.

**Native:** `tools/overlay/u25_06d3_06fb_native.py`, DOSBox-X normal/386 (the host's packaged build, sha256
`99d74601…0df3`), with no masks and IF cleared. **55 of 55 cases are equal.**
