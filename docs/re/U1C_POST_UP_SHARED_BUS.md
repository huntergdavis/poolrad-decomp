# Unit 1C caller after the U68 Up return

`pr_u1c_up_start` and `pr_u1c_up_resume` extend the [U68 post-display exit](U68_POST_DISPLAY_EXIT.md) on the same bus and CPU to unit 1C `+33BD`. The caller supplies the real outer target with IP `339A` and its 1C frame. Standalone `pr_u1c_post_up` begins there: it stores returned `AL` at `SS:[BP-1]`, loads the two live `DS:5D92/5D94` words before writing `DS:4436/4438`, reads the live `DS:84DC` byte and zero-extends it, loads the live `DS:[49D2]` window-0 pointer and writes its word at `+01E4`, then reloads `DS:[49D6]` into ES:DI. The ordered accesses use the shared bus; the stop at `+33BD` is before the window-1 comparison. A U68 zero-movement result remains a terminal `+09A8` loop boundary rather than reaching this caller slice.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. `[339A,33BD)` is 35 bytes, SHA-256 `84b89b9b520e6a3120d26a6c1b6f74ec0ecd562106b3e7850b201c7c3492e4b1`. The earlier [U1C loop audit](U1C_LOOP_3387.md) and [U68 Up audit](U68_ENTRY2_UP_SLICE.md) identified the caller; the span was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `339A`, `BP>=2`, `SP=BP-2`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. If the effective window-0 word offset is `FFFF`, the wrapper stops before its write at `+33B4`, retaining the earlier key, pointer and flag effects. Other window writes use the bus including EGA. The composed session requires a caller-supplied checked 1C target with the same frame relation; the earlier U68, printer and clear provider profiles remain in force. Caller-owned code and data, immutable code, nonwrapping reached return frames and callback constraints are required; this is a bounded profile, not general alias or hardware proof.

Synthetic tests cover idle-to-Up through real display and checked U68 return, the ordered caller effects, a key write aliasing the later pointer load, a window-0 write aliasing the reloaded window-1 pointer, an EGA word write, offset-wrap profile stop, copied target, suspended CPU tamper and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked to the existing provider archive. No original-runtime or native differential is claimed. Window-1 comparison, dispatch, script calls, later movement, visual parity, full gameplay and coverage credit remain outside this slice.
