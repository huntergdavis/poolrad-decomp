# Resident 0802:0020, the GetMem wrapper: raw CPU, composed (t30 side ii)

`pr_r0802_0020` (`src/recovered/resident_0802_0020_cpu.c`) is the raw-CPU, full-state model of START.EXE resident
`0802:[0020,0040)`, the heap-allocation wrapper that 0716 calls at +08BC (ALLOC) for the packed-block buffer. It is one of
t30's side (ii) bodies. Its seam ALLOC@08BC is the sixth of 0716's seven stop sites to have a model.

**A body and its evidence; never a credit.** It is proposed for the `resident_runtime` never-credit class
([RESIDENT_RUNTIME_CLASS.md](RESIDENT_RUNTIME_CLASS.md)). Its subject is the heap, a runtime structure, so no game identity
attaches to it. The membership row is proposed below as text, for par-e to accept.

## Behaviour

    0020 PUSH BP; MOV BP,SP
    0023 AX := ([BP+6] + 7) AND FFF8h          (the size rounded up to an 8-byte granule, in 16 bits)
    002C PUSH AX; LCALL 0AF8:023F (GetMem)       -> DX:AX
    0032 LES DI,[BP+8]; ES:[DI] := AX; ES:[DI+2] := DX
    003C POP BP; RETF 6

- **Narrow value (instance 7 on the cluster list).** The rounding is a 16-bit add. A size of FFF9h–FFFFh wraps to 0–6, and
  the AND makes it 0, so the wrapper asks GetMem for **0 bytes**. GetMem answers **nil, with no RunError**.
  - A near-64 KiB request therefore "succeeds" with a nil pointer, while FFF8h (no wrap) fails with RunError 203 on a small
    heap.
  - Catchers: the independent statement for the `wrap-*` cases; the C test; native (`wrap-fff9/fffc/ffff` under real DOS).
- GetMem rounds again internally. Since the wrapper's request is already a multiple of 8, that second rounding changes
  nothing.
- **Caller:** 0716 passes the directory row's packed size, so the wrap is reachable only with an archive row of packed size
  ≥ FFF9h. 0716's own `packed > 8CA0h` guard sends such a row to its prompt and Quit first. **So in 0716's composition the
  wrap is unreachable**, and it stays a property of the wrapper.

## Composition and contract

- **Composed:** GetMem `0AF8:023F` (`system_getmem_023f_cpu`, a runtime-covered endpoint). Its segment word is read live
  from the code, and it must return to 0032h, otherwise the stop is **CALLEE**.
- **GetMem's stops pass through:**
  - **RUNERROR:** allocation failed; AX = 203 at `0AF8:00E2`; non-returning; the pointer variable is untouched.
  - **HEAP_ERROR:** a non-default HeapError; stopped at its indirect call.
  - **LIMIT:** the declared `max_steps` cap on GetMem's free-list walk.
- No DOS service.
- Exactly 1 MiB of RAM with the relocated code at CS. IP = 0020h; entry SP in `[0020h,FFF6h]`. FFF6h keeps the `RETF 6`
  frame inside the segment.
