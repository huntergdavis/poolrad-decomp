# U68 post-display Up continuation

`pr_u68_290b_exit_start` and `pr_u68_290b_exit_resume` extend the [checked 290B printer return](RES_290B_PRINT_RETURN.md) on the same bus and CPU through the supported U68 post-display exit. Standalone `pr_u68_post_display_exit` begins at unit 68 `+0BA0`. It reads the live local movement flag: zero stops at the prompt-loop boundary `+09A8`; nonzero reads the current `DS:49FA` into `DS:49F9`, then checks `DS:84E4`. If zero, it pushes the source arguments and invokes real `03F1:0137` with bounded loop budgets, checks its return and only then writes `84E4=1`. It reloads the saved key through the live local bytes, executes the U68 epilogue using bus words, and checks CS, IP, SP, BP and SS against a caller-supplied return target. Nested and unexpected-transfer stops retain actual earlier state.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 68 file base `166CB`. `[0BA0,0BAC)` is 12 bytes, SHA-256 `0b83e37f92855bc4803153e4e9017e794e74579edb54509d744afb9516e387c6`; `[0D1C,0D4C)` is 48 bytes, SHA-256 `d394299e70ad8a25cdc7ea04f71f2d85559812a7849414749c3c5c54f00f16b5`. The earlier [entry-2 Up audit](U68_ENTRY2_UP_SLICE.md) identified this path; both spans were independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires the live U68 frame (`BP` in `[0090,FFFA]`, `SP=BP-003Ch`), exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. Caller owns loaded code and bindings, immutable code outside EGA, writes that avoid code, nonwrapping reached return frames, and the [clear provider's](RES_03F1_CLEAR_0137_CPU.md) callback, hardware and budget profile. An optional clear target in the EGA aperture stops at its reached callee frame. If the clear changes BP above `FFFA`, the wrapper stops before the epilogue. These are bounded preconditions, not a general alias or hardware proof. The composed session copies its expected outer return target and clear limits; it does not infer the gameplay caller's target.

Synthetic tests cover idle-to-Up through real display and optional clear, checked outer return and saved key, zero-movement loop boundary, live selector/key alias, already-set clear flag, malformed/profile and nested-budget stops, changed live return word, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked to the existing provider archive. These tests do not establish original-runtime or native differential parity. The zero-movement prompt loop, other keys and selectors, subsequent caller behavior, full gameplay, visual parity and coverage credit remain outside this slice.
