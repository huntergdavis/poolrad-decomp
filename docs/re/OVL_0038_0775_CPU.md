# OVL_0038_0775: the 009E dispatcher's slot-22 handler (raw CPU, a partial chain stopped at +0058)

`pr_u38_handler_0775_cpu` is a raw-CPU, full-state model of GAME.OVR unit `38h` `+0775`, the handler the `009E` dispatcher
reaches through slot 22 (`DS:6880`, stub `0041:0084`, public entry 20), stored by the credited installer `OVL_0038_31A2`
([OVL_009E_0000_HANDLERS.md](OVL_009E_0000_HANDLERS.md) lists it as a named gap). It runs on flat RAM, as the dispatcher's
handlers do, and composes three existing models: the credited resident sidecar lookup `RES_00BA_2199`, the SYSTEM string
load `0AF8:0B0B`, and the partial unit `9E` `+0026` list-node removal reached through its loaded stub.

**Claim, stated narrowly.** This change supplies a body, its test, a static checker and this document. It is a **partial
chain**: the near callee `OVL_0038_0058` (181 bytes, five unready callees of its own,
[STRICT_CANDIDATE_QUEUE.md](STRICT_CANDIDATE_QUEUE.md)) has no model, and the body stops before its call with the exact
state saved. **It is not a strict full-C port, proposes no credit, and flips no dispatcher slot** (slot 22 stays a named
gap in `overlay_u9e_dispatch_0000_cpu.c`, as slot 11 did until its separate grant). No original or native execution was
run: the checker reads the media as bytes only. Task t491; reviewer reserved through the CoS.

## Behaviour

Frame after the far call: `[SP]` IP, `[SP+2]` CS; `[BP+6]` a byte and `[BP+8]` a far pointer A, **both unused by this body**;
`[BP+0Ch]` a far pointer B, a character record. `SUB SP,16h` makes two locals: `[BP-4]` a far-pointer cursor cell and
`[BP-15h]` a 21-byte string buffer. AH is never cleared before the three `MOV AL`/`PUSH AX` pairs, so each callee sees the
live AH in its word argument.

1. **Lookup.** `00BA:2199(B, AH:37h, SS:BP-4)` walks the list at `B+7Fh/+81h` for a node whose byte 0 is `37h`
   ([RESIDENT_SIDECAR_LOOKUP.md](RESIDENT_SIDECAR_LOOKUP.md)); `OR AL,AL` tests its answer.
2. **Found (`AL` nonzero).** Push B, `AH:06h` and `SS:BP-15h`; `0AF8:0B0B` (StrLoad, [SYSTEM_STRING_LEAVES.md](SYSTEM_STRING_LEAVES.md))
   copies the string at `CS:0764` into the buffer and pops only its source (`RETF 4`), leaving B, AX and the buffer pointer
   on the stack as `+0058`'s five argument words; `PUSH CS`; then `+07AB CALL +0058`. **The model stops here (`PENDING`)**:
   IP `07AB`, CS pushed, the five words pushed, the buffer holding the copied string, `DS:681F` untouched. `+0058`'s
   effects, its `RETF 0Ah`, the rest of this body and the return are **not completed paths** on this branch.
3. **Not found.** `DS:681F` := 1; push B, `AH:0Fh`, then `AX := 0`, `DX := 0` pushed (a nil item). `LCALL 00B0:002A` goes
   through the loaded stub of unit `9E` entry 2: the model reads the five stub bytes at the live segment word `CS:07C5`,
   offset `002A`, and requires the loaded form `EAh`, offset `0026` (a far JMP to `+0026`) **before anything is pushed**
   (`CODE` otherwise, IP `07C2`), as the dispatcher model does for its own stubs. It then pushes the return frame and runs
   `pr_u9e_list_release_0026_cpu` at the stub's target segment ([U9E_LIST_RELEASE_0026_CPU.md](U9E_LIST_RELEASE_0026_CPU.md)):
   a nil item searches `B+7Fh` by the type byte `0Fh`; a node with byte `+4` zero is unlinked and freed through its composed
   FreeMem; a node with byte `+4` set reaches that model's own `PENDING` at the dispatcher prefix. Every non-OK status of
   `+0026` (`CODE`, `CALLEE`, `TRANSFER`, `PENDING`, `LIMIT`) is reported here as `CALLEE` with the callee's status and
   diagnostic, and the state as it left it (`DS:681F` still 1). On OK (`RETF 10`): `DS:681F` := 0; `MOV SP,BP; POP BP;
   RETF 0Ah`.

**Statuses.** `OK` (only on the not-found path), `ARGUMENT` (null RAM, CPU or limits, RAM not 1 MiB, IP not `0775h`;
nothing changed), `CODE` (the stub), `CALLEE` (2199 `LIMIT` on a cyclic list without the key; StrLoad cannot stop once the
arguments are valid; `+0026` as above), `TRANSFER` (a callee returned elsewhere) and `PENDING` (`+07AB`). `limits` carries
2199's loop-back cap and `+0026`'s list and heap caps; the diagnostic names the last callee (1 = 2199, 2 = StrLoad, 3 =
`+0026`, 4 = the `+0058` stop), its status, the site and `+0026`'s own diagnostic.

## Validation

**Focused C test.** `test_overlay_u38_handler_0775_cpu.c` passes **41** hand-predicted checks, built with asserts on, on
synthetic RAM with no game bytes (only the three relocated segment words, the loaded-stub form of unit `9E` entry 2,
`+0026`'s checked near-call binding, a 5-character synthetic source string at `CS:0764`, synthetic records and lists). It
covers: the not-found path to `RETF 0Ah` with `DS:681F` 1 then 0, with and without a diagnostic, and with a node of a
third type left untouched; the found path to the `+07AB` stop with the full stack frame, the copied string, StrLoad's
exit registers and the cursor cell, over one- and two-node lists; `+0026`'s `PENDING` surfaced as `CALLEE` with its
dispatcher frame and table pointer; the stub refused as `CODE` on a wrong opcode and on a wrong offset, with nothing
pushed for the call; 2199's `LIMIT` on a cyclic list; the live AH on the key and on the word left for `+0058`; a B offset
that wraps at 16 bits; every `ARGUMENT` case with the CPU unchanged; and a sweep that the world writes nothing outside
its declared bytes.

**Static checker.** `tools/overlay/ovl038_0775_cpu_audit.py` (`CHECKER_ROWS = ('OVL_0038_0775',)`) proves every row of the
"Exact original" table from the pinned media read as bytes: unit and body identity, the 40 instruction starts, the single
`RETF 0Ah`, the four calls and their order, the three fixups and that no other fixup lies in the span, `PUSH CS` before the
near call, the one forward jump, the absence of INT/port/shift/multiply, the two `DS:681F` writes, the string and the
trailing string inside the queue bound, both stub bindings from the descriptors, and that the emitter regenerates the
committed C byte for byte. `--compile-only` builds the model with its four composed sources and binds the symbol with no
media (`CHECKER_BUILD_OK`). The report says `executed: false`.

**Not done, by scope.** No Unicorn differential, no DOSBox-X run, no mutation run: original and native execution of this
body are a separately authorised review. The comparator that would run them stays private until the body is accepted.
`+0026`'s own OK path with an unlink and FreeMem is exercised by that model's test, not here (this test's not-found worlds
leave the list untouched). `TRANSFER` is not reached by any test world.
