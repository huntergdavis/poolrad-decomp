# OVL_009E +0000: the effect dispatcher, translated, composed with the raw-CPU credited unit-0x38 handlers (phase 1; evidence only, no credit proposed; the dispatcher is NOT fully modelled)

This raw CPU body, `OVL_009E_0000` (unit 0x9E, offset 0000h, public entry 1, stub `00B0:0025`), is the game's **effect dispatcher**: it forwards five argument words and executes `LCALL [DI+6828h]` with `DI = 4 * INDEX` (one byte), so the handler is the far pointer that `OVL_0038_31A2` (and, for slot 88, unit 0x86 `+37A7`) stored in the table at `DS:6828h`.
This change is **phase 1** of the VP's option (A) (i21758) as phased by the PM (i21762). It adds the model, its checker, a C test and this document. It proposes **no strict row, no identity row and no manifest row**; par-e accepts or refuses.

**What is and is not modelled, stated once and meant everywhere.** The model composes the dispatcher with the **raw-CPU credited handlers of 42 slots (31 distinct handlers)** and, from phase 2 on, with the adapted semantic handlers listed in the phase-2 table (slot 1 so far). Every other slot in 1..139 STOPS at the `LCALL` with a **named** gap (97 slots), and every index outside 1..139 is **REFUSED**. **Nothing in this document says or implies that the dispatcher is modelled for any slot outside the 42.** The per-slot table is in [`OVL_009E_0000_HANDLERS.md`](OVL_009E_0000_HANDLERS.md); the slot counts below are re-derived from the media by the checker and compared slot by slot with the C table.

## What the body does

    0000 PUSH BP / MOV BP,SP
    0003 PUSH [BP+0Eh] / PUSH [BP+0Ch] / PUSH [BP+0Ah] / PUSH [BP+8]      four argument words, forwarded as read
    000F MOV AL,[BP+6] / PUSH AX                                         the fifth: AL from the byte at [BP+6], AH whatever the caller's AX held
    0013 MOV AL,[BP+10h] / XOR AH,AH / MOV DI,AX / SHL DI,1 / SHL DI,1   DI = 4 * the index byte
    001E LCALL [DI+6828h]                                                the only dispatch
    0022 POP BP / RETF 000Ch

The handlers receive exactly those five words as their own frame (their `RETF 0Ah`). The two `SHL DI,1` set AF under the pinned rule (see the declared split below).

## Role (identity is not claimed)

The role is a **table dispatcher**: it selects one of up to 256 far pointers by an index byte and calls it with the caller's arguments. Measured ownership: **11 far call sites** (unit 0x38 `+0BE5`, `+0BFD`, `+191F`, `+19AC`, `+1FF7`, `+2F40`; unit 0x77 `+1543`, `+1663`; unit 0x86 `+1290`, `+18E3`, `+1A00`) **and 5 near calls inside unit 0x9E** (the near ones were not decoded here). **Eight of the eleven far sites pass a constant index (0Bh twice, 17h, 2Bh, 2Ch, 3Ah twice, 4Eh); three pass a record byte** (unit 0x38 `+2F30` reads `[rec+3Dh]`; unit 0x77 `+1533` and `+164F` read `[rec+3Eh]`). This note makes no claim about identity: the two-factor test is the reviewer's.

## Phase 2: credited SEMANTIC handlers composed through adapters (PM i22058)

A semantic model (`pr_u38_state`, not a CPU) cannot reproduce what its contract leaves out: the frame, the registers and the FLAGS of the handler's last writer, the saved-BP stack residue. **The bar for an adapted slot (the PM's option (a)): the composed Unicorn differential compares full CPU14, FLAGS and all 1 MiB of RAM against the ORIGINAL bytes at the handler's return into `009E`**; an adapter that needs less must instead name every output it does not reproduce and prove it dead with `flag_fold_liveness.py` (flags) or a byte walk (registers), with the command in this document. Where neither holds, the handler needs a raw model, and the slot stays a named gap. **A slot moves into credit scope only with that proof, one adapter at a time.** Each adapter is a hand-written glue function in the same C file that **calls the credited semantic model for the engine-state effect** and supplies the frame, registers and flags itself; the pinned stored FillFlags rule is used for every flag it writes (each helper has a flag-census row).

## Raw contract and stops

`pr_u9e_dispatch_0000_cpu(ram, size, cpu, budget, limits, diagnostic)`: exactly 1 MiB of A20-off RAM (flat; the dispatcher dereferences no caller pointer), IP 0000, **entry SP in [0200h,FFEEh]**. Each dispatcher instruction consumes one unit of budget; **the loaded stub's far JMP and the composed handlers consume none** (the handlers carry their own caps, passed in `limits`). **LIMIT leaves the next unexecuted counted instruction in `cpu->cs:ip`.** The table words at `DS:6828h+4*INDEX` and the loaded stub (`EAh`, offset, segment) must be the original's: **CODE** otherwise, before the `LCALL` runs.

## Domain precondition (declared and asserted; the VP's condition 3)

**INDEX must be 1..139** (slot 88 is stored by unit 0x86, the rest by `31A2`). **Anything else (0 and 140..255) is REFUSED, never guessed, with CPU and RAM untouched** (`PR_U9E_0000_REFUSED`). The assertion is a C-model branch taken before the first instruction, pinned by the C test over all 117 refused indices, by 14 composed-harness cases (the model's result is compared with the *unchanged input*, not with the original, which would have called through garbage), and by the three caller fixtures. The three data-dependent callers keep the index in range only as a **game invariant**; the bytes do not prove it.

### The three data-dependent callers (the VP's condition 4)

For each far caller that passes a record byte, the checker drives the **original caller bytes** (unit 0x38 `+2EDA`..`+2F40`, unit 0x77 `+14D0`..`+1543` and `+1663`) from the function entry through a real state to the dispatcher's entry (the loaded stub's JMP included), with the record byte read at the caller's own `MOV AL,ES:[DI+3Dh/3Eh]` **forced to 0, 140 and 255**, and proves the model **refuses with CPU, RAM and budget identical to the live state**; the in-range control (16) from the same live caller state goes through the full differential (NOP handler) and is equal. Result: **every site reached the dispatcher on the first state tried for each value; 9 of 9 refusals fire; 3 of 3 controls equal.**
**Declared host substitutions in this fixture, and only here:** unit 0x38 `+2EDA` first calls `LCALL 00B0:0052` (unit 0x9E `+0E52`, the list append); the harness replaces that call by its `RETF 000Ch`, because the heap walk behind it does not run on a synthetic state. The unit-0x77 sites need the record bytes `+34h`, `+36h`, `+2Eh`, `+3Eh` (first read above 7Fh) and the DS table rows for the record's type and the active character's two bytes so that `[BP-2]` stays 0 on the `+1663` path; those are set by `set_record_77`.

### Mutation

**22 mutants: 22 caught, 17 by the Unicorn differential and 5 by the C test; no survivor, no equivalent.** Caught by the differential: the refused bound moved to 141 (`refused-140`) and to admit index 0 (`refused-0`); **GAP beating LIMIT at the `LCALL`** (`gap001-limit0`); **`SHL` not setting AF** (the declared split fails); `XOR AH,AH` leaving ZF clear (the budget sweep); the first forwarded word taken from `[BP+0Ch]`; the byte taken from `[BP+8]`; **the index read as a word** (the sweep); the segment word read at `+6829h`; `RETF` popping 0Ah; **the dispatcher's return-address check dropped** (`transfer-133f-final`) and **the handler-return check dropped** (`transfer-133f-handler`); the `LCALL` not charged to the budget; **`+0679` routed to `+0947`**; **`+2976` routed to `+2984`**; **`+2A87` run with the Unicorn shift profile**; **`+1363` given no heap budget**.
**Five mutants survive the differential, as the contract predicts, and are caught by the C test**: the table-word check dropped, the stub-opcode check dropped, the stub-target check dropped, **a handler stop treated as a return** (no composed handler stops in the differential), and the gap kind of an uncredited slot reported as semantic (the differential compares the stop, not the diagnostic's kind). These are exactly the checks the differential cannot exercise because its table and stubs are immutable and its handlers never stop.
The two return-check mutants are caught only because of the `transfer-133f-*` fixtures: a first search over 31 handlers and 40 pointer placements each found no composed TRANSFER, and the fixture was then constructed from the resident's documented stores (`target+3,+0,+7,+6` through the pointer at `character+108h`). The C test and the mutants' C-test runs were built with asserts on (`cc -O1 -fsanitize=address,undefined`, no `-DNDEBUG`).

### Declared environment and substitutions

1. There are none that stand in for original behaviour in the differential: no stub, no INT 3Fh dispatch, no environment service; the whole composition runs as original bytes. **The loaded-stub form is a precondition**, not a substitution: the stubs of units 0x38 and 0x9E are patched to `JMP FAR` (as the other composed audits do) and the model checks that form before it calls.
2. **Host caps for the composed handlers** (their own loop-back, SYSTEM-call and heap/link limits) are generous constants (4,096); no differential case ends in a handler LIMIT.
