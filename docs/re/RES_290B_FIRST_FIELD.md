# U68 to resident 290B first formatted field

`pr_u68_290b_start` composes the existing shared-bus U68 prompt/preflight path, including its idle yield/resume. After U68 reaches its real `+0B9B` call, it checks and executes the far call to resident `00BA:290B`, then runs `pr_290b_first_field`. That standalone bounded prefix starts after the far call, allocates the actual `290B` frame, reads the live selector and coordinates, and handles the selector-at-most-1 route. It reads record word `DS:[49D2]+0192h` through the shared bus and calls real `00BA:1073` to format the full word. It then uses real SYSTEM `0B25` to form the first two-character field. If its length is below two, the source's `CS:28F2` literal is loaded with real `0B0B`, concatenated with real `0B98`, and stored with real `0B25`. The wrapper stops at `290B:+29A6`, before the second field. The literal is supplied by the caller; no game text or media is included.

Source binding: owner START.EXE SHA-256 `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`. Loader-expanded `00BA:[290B,29A6)` is 155 bytes, SHA-256 `388c4474e34944c4d4488f7d4fb05db46c6c19e30681fe73358e209b12212874`; it includes the unimplemented selector-above-1 branch, which stops at `+2929`. The first formatter is the merged [1073 word provider](RES_00BA_WORD_STRING_1073.md); the upstream frame and environment are described by [the U68 prompt contract](U68_PROMPT_098F_DIAGNOSTIC.md). Shared memory recall worker2 session `01a12b3e` identified the `290B` caller and far-return form; the actual instruction span was independently decoded and hashed for this slice.

The caller supplies the genuine live U68 frame, loaded code and relocated call operands, record/window pointers, private literal, device state and all environment services. All nested prompt and U68 contracts apply. The standalone `290B` entry requires exactly 1 MiB RAM with attached EGA, IP `290B`, SP `[043E,FFF0]`, and ordinary CS/DS/SS segment windows below `9000` or at least `B000`. The SP floor accommodates the nested `1073` profile. Each reached flat string leaf is entered with its actual far frame; its live code, source and destination segments are checked for ordinary windows before delegation. The formatter applies its own guards. The live record word is read via the bus, including EGA latches; an effective word offset of `FFFF` stops at `+2961` before the read as an unsupported wrap profile. Code/relocations must stay immutable, caller-owned CPU/diagnostics must be separate from guest state, and callbacks must obey nested nonmutation contracts. Caller-managed data aliases remain live within these restrictions.

A malformed call stops after its earlier source pushes and effects. A flat-leaf profile stop retains its far frame; formatter/leaf failures and return mismatches preserve state and identify the reached stage. The bridge propagates prompt yields and nested stops, and never retries a terminal stop. `FIRST_FIELD` means only that `+29A6` was reached; the second field, later string construction, `03F1`/printer display calls, `290B` return, U68 return, gameplay and native/visual parity are not implemented or claimed. It grants no credit.
