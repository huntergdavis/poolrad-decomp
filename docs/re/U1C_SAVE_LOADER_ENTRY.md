# ECL SAVE to U25 operand-loader entry

`pr_u1c_save_start` and `pr_u1c_save_resume` extend the [ECL dispatcher prefix](U1C_ECL_DISPATCH_PREFIX.md) on the same bus and CPU only when it reaches opcode `09` handler `+0292`. Standalone `pr_u1c_save_loader_entry` executes the source `PUSH BP; MOV BP,SP; SUB SP,4`, preserves AH while pushing operand count 2, validates the reached far call at `+029B`, builds its real return frame, and reads the live `002A` stub segment. It checks the reached stub for a far jump to offset `0000`, reads the live target segment and stops at the real U25 operand-loader entry. Other handler entries and earlier boundaries remain distinct terminal outcomes. The loader body and SAVE effects are not executed or fabricated.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. `[0292,02A0)` is 14 bytes, SHA-256 `8bf55107e122540a4169e37ce6e5f1d3173207a5adf1005fbaefc98f1c93b948`; complete SAVE `[0292,02E0)` is 78 bytes, SHA-256 `7f66f8be811fe835d3ed3ab0fc0772f57e10ab39b5b5beda8aa2542262f92ebb`. Prior [SAVE model](FUNCTION_LEDGER.md), [U25 loader contract](U25_LOADER_0000.md), and candidate CPU evidence supplied leads; the source span was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `0292`, `SP` in `[000C,FFFC]`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session requires a 1C caller BP of at least 32 to keep this frame in profile and inherits earlier U68, 1C and provider requirements. Caller owns the actual loaded code and stub binding, immutable code outside EGA, writes avoiding code and nonwrapping reached return frames. A malformed handler call stops at `+029B`; a malformed stub stops at its reached `+002A` frame; a nonordinary stub or loader segment stops at the reached target frame. The loader's own stricter stack, budgets, immutable-code and flat-RAM profile must be evaluated separately before invoking it. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up with opcode `09` through the actual loader frame, a different handler boundary, preserved AH and SUB flags, malformed call, malformed/wrong-target stub, nonordinary stub/loader targets, a stack/latch alias, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive. The existing SAVE CPU draft uses candidate doubles, and the full U25 loader uses flat RAM; neither establishes shared-bus execution under arbitrary live aliases here. Loader effects, SAVE completion, later dispatcher cases or runner iterations, original-runtime/native differential, movement, visual parity, full gameplay and coverage credit remain unverified.
