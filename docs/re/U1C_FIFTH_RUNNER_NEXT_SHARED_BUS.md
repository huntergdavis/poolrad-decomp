# Runner iteration after fifth SAVE

`pr_fifth_runner_start` and `pr_fifth_runner_resume` extend the [fifth dispatcher return](U1C_FIFTH_DISPATCH_RETURN_SHARED_BUS.md) through the existing [one-iteration runner helper](U1C_RUNNER_NEXT_SHARED_BUS.md). The helper rereads the live gates; it either checks a runner return or fetches the next opcode and stops at dispatcher `+2F2D`. The two outcomes are distinct, and the runner-return target is copied from the outer frame at start. Earlier fifth-store and other outcomes pass through unchanged. Malformed reached code stops after preceding effects. This composition reuses [runner iteration after fourth SAVE](U1C_FOURTH_RUNNER_NEXT_SHARED_BUS.md).

Start rejects outer BP below 56 or any nonempty nested dispatch-return, handler, store-return, low, dispatch, classifier-return, classifier, store, value, pair-return, pair, slot, branch, loader, SAVE, dispatcher or runner before mutation. It inherits earlier frame, budget, code and caller requirements. These are bounded assumptions, not a general alias or hardware proof. No original bytes are embedded.

Synthetic integration covers idle-to-Up fifth low no-op through a sixth opcode fetch and dispatcher entry, copied target, a fifth later opcode, earlier stops, and atomic rejection and retry for each nested phase and invalid BP. Existing standalone tests cover runner return and malformed code; fifth-route writes, runner-return mapping and most earlier stop mappings are not separately driven here. The wrapper and fixture pass strict-warning ASan/UBSan with the provider archive uninstrumented. No native differential, next handler, unbounded loop, movement, visual parity, full gameplay or coverage credit is claimed.
