# Unit 0x3B0 +0x0711: bounded node-list selector

`src/recovered/overlay_u3b0_leaf_0711.c` models the complete DOS v1.3
`GAME.OVR` unit `0x3B0:+0x0711..+0x07A3` body. This is a call-free
near-called leaf. Its classification as a game routine remains
**provisional**: no natural saved-game caller frame was reached and no
strict full-C count is claimed.

The pre-implementation `deja "poolrad U3B0 +0711 147 byte list leaf original
C parity"` query timed out (exit 124), so it supplied no reusable claim.
The local stack, `LES` and far-node pointer approach was reused from the
reviewed U3B0 entry1 work at commit
`e8b9832e1e896f45cd9afa6060147c0aa7272aba`; the synthetic native
capture pattern was reused from U9E entry0 commit
`e75b7615575cfe5897035525843b54e99e50b69e`. Both were checked
afresh against this function's original bytes.

| Body | File `[0x2CFE0,0x2D073)`; unit `[+0x0711,+0x07A4)`; 147 bytes / 52 instructions; SHA-256 `a3510458227e9373193717033475fa31fe5d1bf0ef01a33da6582726d6650092` |

| Exit | `RETF 8` at `+0x07A1`; no calls inside body |

The caller supplies an original far head pointer at `[BP+8/+0A]` and a
signed word bound at `[BP+0C]`. Starting at the head, the body walks up
to that bound while the current far pointer is non-null. For each visited
node, a nonzero byte at `ES:[DI+0x29]` updates the saved candidate to
the current node. It follows the next far pointer through words at
`ES:[DI+0x2A/+0x2C]`. After traversal it returns the last saved
candidate in DX:AX. If none was saved, it checks the original head's
`+0x29` byte once more and returns that head when nonzero; otherwise it
returns `0000:0000`. The C model preserves the original stack locals,
signed `JGE`, `OR`/`CMP`/`INC` flags, ES/DI effects, offset arithmetic,
and 16-bit SP wrapping between far-return words.

`tests/recovered/check_overlay_u3b0_leaf_0711.py`. The DOSBox-X
normal-386 synthetic oracle is `tools/overlay/u3b0_leaf_0711_native.py`;
it copies the exact original 147 bytes into a separate code segment at

`resources/u3b0-0711-parity/native/report.json`. The DOSBox-X executable
has SHA-256
`99d7460153175d13a21036fb4b0e7524e05b6a1e50cd4e59f2470afad12a0df3`.

`resources/`. The focused C11 `-Wall -Wextra -Wpedantic -Werror`
