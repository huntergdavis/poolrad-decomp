# Unit 0x3B0 +0x0711: full-state node-list selector

This change brings the unpublished implementation from
[1f57e4ec65081518d77adfdae051c1a5bb59b33f](https://github.com/huntergdavis/poolrad-decomp/commit/1f57e4ec65081518d77adfdae051c1a5bb59b33f)
onto current main, expands original/native evidence, and documents the
execution profile. The recovered C body is unchanged from that source.
Acceptance and identity/count credit remain with independent review.

The resumed deja query for U3B0 +0711 returned no matches. The earlier
implementation attributes its stack/LES approach to U3B0 entry1 commit
e8b9832e1e896f45cd9afa6060147c0aa7272aba and its native capture to U9E

technique from U38 +2002 PR #896 (2c6fde3ca442ef46656326f55bef1c054ad5d4da).

The corrected schema-7 queue-final-2 export has 84 composable rows and
ranks this target 462 / score 16, penalized for its unpublished branch.
Higher hard rows already have models, are under review (#896), or are
excluded by the raw-CPU interface caveats. This selector has no callees.

At entry, SS:SP contains return IP/CS, one unused argument word, a far
head pointer, and a signed word bound. The routine initializes a local
count to zero, then traverses while the current pointer is non-null and
the count is below that signed bound. A nonzero node byte at +29 records
the current node as the candidate. The next pointer comes from separate
word loads at +2A/+2C. Positive bounds limit cyclic lists as well.

DX:AX returns the last recorded node. If no candidate exists, the routine
reads the original head's +29 byte again and returns that head if the
byte is nonzero; otherwise it returns zero. A null head still causes the
fallback read at physical 0000:0029. The focused C regression asserts the
resulting flags for byte 80, preventing a fabricated null-pointer shortcut.

The original audit covers all 256 flag bytes in each of three node
positions and the zero-bound fallback; signed bound endpoints; null,
short, cyclic, and physically aliased lists; stack-local/node aliases;
node-word and stack-LES seams; relocated segments and A20 wrapping; and
128 deterministic randomized RAM fixtures. The cyclic maximum-bound
case asserts exactly 32,767 original node visits. A two-million-instruction
budget fails the audit if exceeded; no case is silently skipped. The
original executes its actual outer RETF before the complete state comparison.

The declared memory profile is 20-bit A20-wrapped RAM, with scalar words
and LES read physically contiguously after calculating their 16-bit
effective offsets. Node-link word effective offsets are formed separately,
as in the two original MOV instructions. The model preserves live stack
aliases and all 14 CPU words. Hardware exceptions, interrupts, CPU storage
overlapping RAM, and executing-code aliases are outside its contract.
Undefined AF after logical operations is cleared, matching the measured
Unicorn/DOSBox-X profile; this is not an architectural definition of AF.

RETF pops IP and CS as separate 16-bit stack words, matching the DOSBox-X
normal386 captures at SP=FFFE/FFFF. Unicorn differs there, so those two
entry SP values are checked natively. LES operands at FFFD..FFFF have
Unicorn evidence only; native behavior at that seam is unmeasured.

Twelve native cases use SP=FFFB/FFFE/FFFF. They cover zero, one/two-node,
negative 8000, and maximum positive 7FFF bounds with node bytes 00, 01,
80, and FF. Each compares all 14 CPU words and 80 selected RAM bytes:
64 stack bytes, one adjacent physical byte, and 15 node bytes. Native
coverage is not whole-RAM coverage. The ignored native report records
COM/result SHA-256 values for each 108-byte capture.
