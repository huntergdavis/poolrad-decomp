# Unit 0x25 +0x1788: provisional full-state public entry 14

`pr_u25_entry14_1788` translates the complete U25 public entry 14 (far stub
`2B:0066`) over caller-owned A20-off 1 MiB RAM and a fourteen-word CPU
frame. It composes its near callee `+156D` through the full-state
[`pr_u25_tilde_caps_156d`](U25_TILDE_CAPS_156D.md), whose seven runtime
calls are forwarded to this routine's hook. The far callee U3B0 `+0D9A` and
two SYSTEM StrStores are fail-closed call-site callbacks. **Game identity
is not asserted, and no strict full-C, identity or count credit is
requested.**

## Original boundary

Ignored DOS v1.3 `GAME.OVR` is 206,105 bytes, SHA-256
`872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`.
Unit `0x25` starts at file `0x74D3`. The routine is exactly file
`[0x8C5B,0x8CE8)`, unit `+1788..+1814`, **141 bytes / 67 instructions**,
SHA-256 `f5c93434b2d1ea60dbcc779c63e3aaf95fcf5a1f60b92893ec202b1b18726016`.
It is straight-line code with no jumps, and its only return is
`+1812 RETF 0x28`. It follows `+1684`'s `RETF 0x12`, and `+1815`'s prologue
follows directly.

The only caller is the far call through `2B:0066` at U1C `+1053`. A
decode-aligned scan of all ledger functions found no other caller. No
source, document, ledger row, branch or sibling-clone file owned this
routine at `e1bd61c`.

## Behavior

The routine takes twenty argument words, `[BP+6]..[BP+0x2D]`, and reserves
`SUB SP,0x154`.

1. StrStore copies far string `[BP+0x2A]` into local `[BP-0x29]` with cap
   `0x28`, and far string `[BP+0x26]` into local `[BP-0x129]` with cap
   `0xFF`.
2. It calls `+156D` with dest `[BP-0x153]` and src `[BP-0x129]`. This filters
   the local copy in place. The `[BP-0x153]` result is never read again.
3. It re-pushes the remaining arguments in the original order, with the two
   string arguments replaced by the two locals, and calls U3B0 entry 4. The
   byte arguments use `MOV AL; PUSH AX`, so AH carries through.
   - **Forwarded unchanged:** far pointers `[BP+6]`, `[BP+0xA]` and
     `[BP+0xE]`; byte `[BP+0x12]`; words `[BP+0x14]` and `[BP+0x16]`; bytes
     `[BP+0x18..0x24]`.
   - **Replaced:** the two string arguments become the locals `[BP-0x129]`
     and `[BP-0x29]`.
4. It stores the callee's AL to `[BP-0x12A]` and returns with `RETF 0x28`,
   with AX and flags as the callee left them.

The caller's own strings are only read, never modified. Every argument is
re-read from live SS RAM where the original reads it.

`+156D`'s `RETF 8` reads its return words from RAM. If a forwarded hook
changes them, the composed call returns somewhere other than `CS:17C6`, and
this routine reports `PR_U25_1788_TRANSFER` with that CPU state rather than
inventing a continuation.

Flags reach the callees and the return unchanged. The first StrStore sees
the `SUB SP` flags. Every later call sees its predecessor's returned flags,
and the return carries U3B0's flags.

## Verification

`test_overlay_u25_entry14_1788.c` uses a synthetic runtime with the decoded
SYSTEM effects and a recording U3B0. It checks:

- the call sequence through the composed `+156D`
- the capped 40-byte copy and the filtered 255-byte local, with the caller's
  strings unchanged
- the exact layout of all twenty forwarded words, including AH carry-through
- the stored AL and the return
- an abort at both outer StrStores, inside `+156D`, and at U3B0
- the TRANSFER case
- argument rejection

It passes strict C11 `-Wall -Wextra -Wpedantic -Werror` and ASan+UBSan.

`check_overlay_u25_entry14_1788.py` pins:

- the body, `+156D` and StrStore hashes
- the single near call and the ten call sites with their targets
- the neighbouring bytes and both `RETF` encodings
- the seven SYSTEM returns

Its source pins have run statically. Its Unicorn differential has **not**
run and waits for a PM serial slot. When run, it executes both routines'
original bytes over 72 cases:

- three name lengths × six strings × two sets
- SS-alias, high-stack and U3B0 return-rewrite cases
- 30 seeded cases

For each case it compares all 1 MiB of RAM, the CPU words and every call
trace, and requires every instruction start and every conditional outcome.
Only returning paths are compared, so TRANSFER is covered by the focused
test only.

No reached native `+1788` frame was searched. Callee and caller native
parity remain open.
