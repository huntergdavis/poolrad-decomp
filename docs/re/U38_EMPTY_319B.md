## C contract and measured parity

`pr_u38_empty_319b` models the whole entry against 1 MiB RAM and the 14-field CPU frame. Even though it has no game-data effect, `PUSH BP` writes the saved BP word at `SS:SP-2`; the far return then consumes its IP and CS and ten argument bytes. The two return words use separate 16-bit stack offsets: IP at entry `SP`, CS at `(SP+2)&FFFF`. A word read itself uses contiguous physical bytes, masked at 1 MiB. All other registers and all FLAGS bits remain unchanged. Host null, short-RAM, and wrong-IP inputs return `ARGUMENT` before mutation.

The original-byte checker pins both input hashes, the entry inventory, installer boundary, no-fixup span and four decoded instructions. In 192 cases it compares the complete 1 MiB RAM and all 14 CPU fields against Unicorn, varying six SS segments, eight stack pointers, four saved BP and flag values, including near-1 MiB stack addresses and `RETF 10` SP wrap. The selected frames keep the return words inside one 16-bit stack window and all physical accesses inside Unicorn's mapped 1 MiB. Single-step trap flags, A20-crossing writes, and far-return CS reads across `SP=FFFF` are outside this emulator comparison.

Four DOSBox-X normal-core synthetic far-entry frames execute the seven pinned bytes with saved BP values `0000,0123,7777,FFFF`. They match original-byte Unicorn across all 14 CPU fields and 52 stack bytes. Ignored capture products stay under `resources/u38-319b-parity/native/`; capture SHA-256 `5d7adb413cb3398d33e7437a5a159551d6d8174572a394cbfd94cdbcd32ef885`.

Two additional DOSBox-X normal-core frames use entry `SP=FFFE` and `SP=FFFF` in a separate stack segment. These execute the original seven bytes and compare directly with the C model across all 14 CPU fields and 52 logical stack bytes around the wrap. They verify that the CS pop uses wrapped 16-bit offset 0 or 1, while each word's bytes are physically contiguous. The ignored wrap capture is under `resources/u38-319b-parity/native-wrap/`, SHA-256 `0d68da9fbc92bbd96269ed97c7c0ac9d61d0d7f3901fcd3f3e77f68d70a9a361`.
