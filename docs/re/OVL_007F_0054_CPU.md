# OVL_007F +0054: translated, evidenced bounded-subtraction body around +0000 (evidence only; no credit proposed)

This raw CPU body, `OVL_007F_0054` (unit 0x7F, offset 54h, public entry slot 1), takes a record pointer, a word and an out pointer. It asks [`OVL_007F_0000`](OVL_007F_0000_CPU.md) for the record's class value V, reads a
word W at record+0102h, and if W plus the argument (16-bit) is above V it stores V - W through the out pointer and returns 1; otherwise it stores 0 and returns 0. It composes #1418's `+0000` model and, through it, the resident
13AB/11EA closure. This change adds the model, its checker, its native harness and this document. It proposes **no strict row, no identity row and no manifest row**; par-e accepts or refuses.

31 starts, **two near calls to +0000 (at 0061 and 0080, each after `PUSH CS`)**, no far call, interrupt or port instruction, **exactly two jumps (the conditional `JBE 0093` at 0073 and `JMP 009F` at 0091)**, the single `RETF 000Ah`, and **no relocation in the span**. The two call sites'
bytes (`E8` and the displacement) are checked by the model before each call. The composed closure is `+0054` 31 + `+0000` 12 + resident `13AB` 89 + `11EA` 62 = **194 instruction starts**, all reached by the differential.

## What the body does

Frame after the call: `[SP]` IP, `[SP+2]` CS, `[SP+4]` the out pointer's offset, `[SP+6]` its segment, `[SP+8]` a word `extra`, `[SP+10]` the record pointer's offset, `[SP+12]` its segment. `RETF 000Ah`.

1. `PUSH BP; MOV BP,SP; SUB SP,2`. `PUSH [BP+0E]; PUSH [BP+0C]; PUSH CS; CALL 0000`; `MOV DX,AX` (V).
2. `LES DI,[BP+0C]`; `AX := ES:[DI+0102]` (W); `ADD AX,[BP+0A]`; `CMP AX,DX`; `JBE 0093`.
3. **Above:** `[BP-1] := 1`; call `+0000` again with the same pointer; `LES DI,[BP+0C]`; `AX := AX - ES:[DI+0102]` (W is **read a second time**); `LES DI,[BP+6]`; `ES:[DI] := AX`; `JMP 009F`.
4. **Not above:** `[BP-1] := 0`; `LES DI,[BP+6]`; `XOR AX,AX`; `ES:[DI] := AX`.
5. `AL := [BP-1]` (the flag byte is **read back from the frame**); `MOV SP,BP; POP BP; RETF 000Ah`.

The flag byte at `[BP-1]` and the saved BP that `POP BP` restores sit directly below and above the one word the body stores through a caller-supplied pointer, which is what makes the aliasing fixtures below meaningful.

## Role (identity is not claimed)

The role is a **bounded subtraction on a character record**: it returns whether `W + extra` exceeds the record's class value (the `+0000` result, class value plus 1,500) and stores the excess of the class value over W. Measured ownership: **six near callers inside unit 0x7F** (sites 021A in the body at 0203, 075D and 07D0 in the body at 063A,
0A9D in the body at 0A88, 1D4A and 209D in the body at 19B2) and **one fixup-backed far caller from unit 0x77** (site 1E3C in the body at 1CEE), reaching this body through unit 0x7F's entry-1 stub. This note makes no claim about identity: the two-factor test is the reviewer's.

## Pointer census

Every pointer the body dereferences that it did not create, and whether the access goes through the bus (`pr_bus`: with an EGA attached, a byte access to A0000..AFFFF goes to the planes instead of RAM). **This body, unlike `+0000`, dereferences caller-supplied pointers itself.**

| Pointer | Source | The body's own access | Bus? | Also dereferenced by |
| --- | --- | --- | --- | --- |
| record pointer (offset `[BP+0C]`, segment `[BP+0E]`) | caller's frame | **word read at `+0102h`, twice** (0069 and, on the above path, 0086) | **yes, through the bus** | `+0000` and resident `11EA`: bytes at `+10h` and `+16h`, **flat RAM** (their contract) |
| out pointer (offset `[BP+6]`, segment `[BP+8]`) | caller's frame | **one word store** (008E on the above path, 009C otherwise) | **yes, through the bus** | none |
| the entry frame, the body's own frame (flag byte `[BP-1]`, saved BP, the pushed arguments) | caller / created here | flat SS reads and writes | no | `+0000`'s own frame sits below |
| the call-site bytes at 0061..0063 and 0080..0082 | code | read for the CODE check | no | none |

**Where the exposure lives:** in the body's own two bus accesses (checked) **and** in the resident helper's flat reads of the record's `+10h` and `+16h` bytes (a contract limit shared with `OVL_007F_0000_CPU.md`). A record placed in the aperture therefore gets **W from the planes and the class bytes from RAM**, which is neither
what the machine does nor consistent; that mixed state is outside the contract and is shown, not claimed (see the C test below).

### What pins the bus claim

Unicorn has no planar EGA, so the differential cannot see a model that bypasses the bus (the mutant that does so survives it). The claim is pinned by the **C test, which attaches an EGA** (`pr_ega`) and predicts by hand: an out pointer at `A000:0100` on the above path writes `40h` and `05h` to **all four planes** at offsets 0100h and 0101h and leaves the RAM bytes there untouched; without an EGA the same state writes the RAM bytes; a record whose `+0102h` word lies in the aperture reads `W = 0100h` from plane 0
while the RAM bytes there hold `1234h`, and the result (`0540h`) shows which was used. **The mutant that bypasses the bus is caught by that test.** No native EGA run was made for this body.

### Adversarial fixtures (a caller-supplied pointer placed on the memory the body itself creates)

The body creates its frame, and the original's own store reaches it. The fixtures place the out pointer and the record's `+0102h` word on every byte from `BP-20h` to `BP+11h`, on both branches:

- **`clobber-out-bp-20 .. clobber-out-bp+11` (50 positions x 2 branches = 100 cases)**: the store lands on the unused local, **the returned flag byte at `BP-1` (so AL becomes the stored low byte)**, **the saved BP's low and high bytes (so the restored BP changes)**, **the return address (so the return transfers elsewhere)**, the argument words (the out pointer's own words, `extra`, the record pointer) and the caller's words above them. **9 of these end in TRANSFER** (`BP+1` above and `BP+2` to `BP+5` on both branches; `BP+1` on the not-above branch stores zero over a return-IP low byte that is already zero, so it does not transfer); the original and the model agree on the garbage CS:IP and on every other byte.
- **`rec102-at-bp-20 .. rec102-at-bp+11` (100 cases)**: the record is placed so its `+0102h` word is the frame word at that position. **`rec102-at-bp-1` makes the first and second read of W differ**, because the body stores `[BP-1] := 1` between them; the mutant that reuses the first read is caught by exactly this case.
- **`out-and-rec102-same-bp{-3,-1,0,+2,+4,+6}` (6 cases)**: the out pointer and the `+0102h` word at the same frame word; the `+2` and `+4` cases are the other **2 TRANSFER** cases (11 in all).
- **`out-is-rec102`, `out-is-rec10`, `out-over-rec-pointer-words`, `rec-over-args`**: the store onto the record's own W and class byte, onto the record pointer words, and the record's W onto an argument word.
- **A store into the body's own code is outside the contract** (self-modifying code; code is immutable here) and is not a case.

### Mutation

**15 mutants, 15 caught: 14 by the Unicorn differential and 1 by the C test.** Caught by the differential: the JBE ignoring ZF (caught by the equality case), the CMP operands swapped, the record word read at +0100, `extra` read from `[BP+8]`, the stored word computed as an ADD, the flag byte values swapped, the out pointer words swapped, RETF popping 8 bytes, **the return-address (TRANSFER) check dropped (caught by `clobber-out-bp+02-above`: the model returns RETURNED where the original transfers)**, XOR AX,AX leaving PF clear, the JBE not charged to the budget, the call-site displacement check changed, MOV DX,AX dropped, and **the second read of W reusing the first (caught by `rec102-at-bp-01-above`)**.
**The mutant that makes the out store bypass the bus survives the differential, as predicted, and is caught by the C test**, which attaches an EGA: a store at `A000:0100` must reach all four planes and leave the RAM bytes alone. Nothing in the differential can see it, because Unicorn has no planar EGA; this is why the bus claim in the pointer census names the C test and not the differential. The mutation run uses 20 of the cases, prints a START and a result line per mutant, and a first version of the TRANSFER mutant did not compile (an unused variable under `-Werror`); it was rewritten to keep the variables referenced, not counted as a catch.

### Declared environment and substitutions

1. There are none that stand in for original behaviour: no stub, no INT 3Fh dispatch, no environment service. The whole call runs as original bytes in the oracle.
2. `run_original` in the `+0000` audit gained one defaulted parameter (`frame_key`), so this audit can capture the frame at the `+0000` entry; the `+0000` audit's behaviour and results are unchanged.
3. TF is excluded from the random flag words (a single-step trap is an interrupt, outside this model), and FLAGS bit 1 is always set (the machine reads it as 1).

### Native corroboration (partial; packaged DOSBox-X, not the pinned build)

DOSBox-X normal core, 386, **79 synthetic cases that return**, plus **2 reported probes**. The record, the stack and the data segments are written to files and loaded by real DOS reads; the oracle program provides the entry frame's return address. Cases: 12 raw class bytes x {V-1, V, V+1}, four `+16h` edges, four flag images, SP at both bounds and an odd SP, **the out store at ten frame positions x two branches** (the local flag byte, the saved BP's low byte, the pointer words; never the return address, which cannot return to the oracle program) and **the `+0102h` word at six frame positions x two branches**.
Compared with the C model on identical state: all 14 CPU words and **25,888,932 bytes** (five 64 KiB regions per case plus the CPU words), **0 mismatches, no masks.** The host's **packaged `/usr/bin/dosbox-x` 2026.01.02** (SHA-256 `99d7460153175d13a21036fb4b0e7524e05b6a1e50cd4e59f2470afad12a0df3`) was used, **not the pinned `5a9c7c53` build**.
**IF was cleared in every native case.** The first native run had IF set and failed in one two-call case with 18 bytes of stack garbage below SP that the model does not write: a real timer interrupt had pushed its frame onto the observed stack. That was a flaw in my harness, not in the model; the native cases now run with interrupts disabled. (The `+0000` native run used IF-set flag images in two cases and passed; it did not hit an interrupt, which is luck, not a guarantee.)

**The two probes (reported, not asserted):** a record whose `+0102h` word straddles offset FFFFh (`probe-rec-straddle-feff-fd`) and an out store at offset FFFFh (`probe-out-straddle-ffff`). In both, **the packaged DOSBox-X result equals the model's physically contiguous convention**.

### Which way verdicts move under a convention split

- **Word accesses that straddle FFFFh** (the corpus and Unicorn read and write the second byte at the next physical address; an explicit 16-bit word access on a machine that wraps the offset would use `seg:0000`): three Unicorn cases depend on it, `rec-top-fefd` and `out-top-ffff-above` / `-not`. The pinned DOSBox-X build is recorded as wrapping such accesses, so **those three cases, and only those, would move from pass to mismatch on it**; the packaged build used here does not show the split (the two probes above). **Not run on the pinned build.**
- **A store or read through a pointer in A0000..AFFFF:** the body's two accesses go through the bus (pinned by the C test); the resident helper's reads of the class bytes do not (flat). On a machine whose plane reads differ from flat bytes, a record or out pointer in the aperture moves from a result the model can reproduce to one it cannot, in the helper's reads only. No differential case places a pointer there.
