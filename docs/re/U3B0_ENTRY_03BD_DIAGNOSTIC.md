# Unit 3B0 entry setup to prompt input

`pr_u3b0_entry_03bd` begins with the real unit 3B0 entry's caller-supplied far frame and arguments. It executes `PUSH BP`, frame allocation and the original two SYSTEM `0B25` string-store calls, clears the selected-key flag, computes the mode byte, invokes the real nested `+00CB` item splitter, performs the source's selection clamp and output initialization, then joins the existing `+0432` clock, label, drawer and single-pass input composition. The nested clock/draw result is returned explicitly. Reaching it does not itself mean the prompt completed or entry2's host hook is provided.

Source binding: owner GAME.OVR SHA-256 `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 3B0 file base `2C8CF`, span `[03BD,0432)` 117 bytes SHA-256 `9fcfc792af08099e63c87869af04c1a35bc2e41a52265f1c891981799612759d`. String calls at `+03D2` and `+03E5` and nested near call at `+040C` are checked live; call segments are read live. No game bytes are included.

The caller owns the actual entry far return, Pascal arguments, loaded stable code and relocation identity, input strings, output pointer, EGA, font and all environment services. Entry requires exactly 1 MiB RAM with EGA attached, IP `03BD`, SP `[01D2,FFE4]`, and CS/DS/SS below `9000` or at least `B000`. This conservative segment-window rule prevents any byte, including a word's second byte, from entering A0000–AFFFF while the flat-RAM `0B25` and `+00CB` models run. Before each string-store delegation the live pushed source segment is checked by the same rule; rejection stops at the call with its already-pushed arguments and prior effects preserved. The output-byte write at `+042A` uses the shared bus, including EGA effects. Code and call operands must remain immutable against all writes; caller-provided CPU, environment and diagnostic must be separate from RAM and devices. All nested clock, printer, drawer, item-split, FIFO and callback contracts apply. DOS time must obey the clock's no-RAM-write and stable-bus rules.

A malformed call stops at its instruction after preceding effects and argument pushes; raw callee stops and unexpected returns preserve state and report their nested status. Invalid initial arguments are atomic. The diagnostic phase identifies either string copy, item split or the joined downstream path. There is no arbitrary-PC resume. [Item split](U3B0_ITEM_SPLIT_00CB.md) and [clock/drawer](U3B0_CLOCK_DRAW_0432_DIAGNOSTIC.md) document the composed models and further limits.

Synthetic tests supply an actual entry frame and real raw string stores, splitter, clock, label printer, EGA, drawer and FIFO input. They cover a successful Up route, each string source rejected at the EGA boundary, preserved first copy on second rejection, malformed second call and nested call, nested split failure, and atomic invalid entry. The wrapper and fixture also passed a strict-warning ASan/UBSan run linked to the existing provider archive. These inputs do not establish original-runtime or native equivalence for this composition, full prompt looping or entry2 host integration, visual parity, gameplay, or coverage credit.
