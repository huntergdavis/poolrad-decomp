# U25 operand tag branch

`pr_u25_tag_start` and `pr_u25_tag_resume` extend the [first operand prefix](U25_OPERAND_PREFIX_SHARED_BUS.md) on the same bus and CPU from `+005F`. Standalone `pr_u25_operand_tag` rereads the live local index and tag. Tags `1`, `2` and `3` increment the live script PC, reload the script pointer, fetch the third byte through the bus, reread the live local index, write the corresponding `DS:7045+index` byte and stop at the common loop test `+0121`. Tag `80` stops at `+009A` and tag `81` at `+00D7`, before either string path changes state. Other tags reach `+0121` after the source comparisons. Earlier zero-count, prompt-loop and other-handler boundaries remain distinct terminal outcomes. No string-helper or subsequent-operand effects are fabricated.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 25 file base `74D3`. `[005F,00D7)` is 120 bytes, SHA-256 `cbfd951bd4e0ac17aa337ba80394e7f18d107432cbe159f5639b6c069cc309b9`. The existing [complete flat-RAM loader audit](U25_LOADER_0000.md) supplied prior evidence; these instructions and branch destinations were independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `005F`, `BP` in `[0008,FFF8]`, `SP=BP-8`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session inherits the earlier U68, 1C, SAVE and loader-prefix profiles. Caller owns real code and bindings, immutable code outside EGA, writes avoiding code and nonwrapping reached return frames. Third-byte reads use the shared bus, including EGA latches and 16-bit effective-offset wrapping. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up through numeric tag `2`, all three numeric tags, other-tag comparison flags, both string boundaries and a composed string stop, EGA third-byte read and latches, a PC write aliasing the reread local index, copied target, suspended CPU tampering and invalid-frame atomicity.
