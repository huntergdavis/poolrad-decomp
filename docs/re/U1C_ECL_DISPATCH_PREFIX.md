# Unit 1C ECL dispatcher prefix

`pr_u1c_ecl_start` and `pr_u1c_ecl_resume` extend the [first runner dispatch](U1C_RUNNER_PREFIX_SHARED_BUS.md) on the same bus and CPU into unit 1C `+2F2D`. Standalone `pr_u1c_ecl_dispatch_prefix` pushes the live BP, reads `DS:6F7F` after that push, and follows the source compare chain through opcode `09`. For matched opcodes it preserves the final comparison flags, pushes CS, validates the reached near call and its live relative target, pushes the source return IP, and stops at the handler entry. Opcodes `00..03` reach `0001`, `00F4`, `0111`, `0126`; `04..07` reach `01A3`; `08` reaches `0234`; `09` reaches `0292`. Later opcodes stop at `+2F8C` before the next comparison, with the last comparison flags and prologue effects retained. No handler body or dispatcher return is fabricated. Earlier runner return, prompt-loop and alternate-dispatch boundaries remain distinct terminal outcomes.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. `[2F2D,2F8C)` is 95 bytes, SHA-256 `3b9712886303f394eb6c8142482370ed0ebd60ab3c1b479e200d6b2708f5c246`; the full dispatcher `[2F2D,3171)` is 580 bytes, SHA-256 `a145b1fb2a0bf37ad106ea3f220756ba2820aa97aa72536fcef8f457141ccf51`. The earlier [3171 and dispatcher audit](U1C_ECL_RUN_3171.md) and [ECL contracts](ECL_CONTRACTS.md) supplied prior evidence; the chain was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `2F2D`, `SP` in `[0006,FFFC]`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session requires a 1C caller BP of at least 20 to keep this frame in profile and inherits the earlier U68, 1C and provider requirements. Caller owns real code and bindings, immutable code outside EGA, writes avoiding code and nonwrapping reached return frames. A malformed or wrong-target near call stops after the source CS push at that call, retaining the prologue and comparison flags. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up through real display and opcode `09` to the SAVE handler frame, each supported opcode, later-opcode stop, comparison flags, malformed and wrong-target calls, a saved-BP push aliasing the subsequent opcode latch, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive.
