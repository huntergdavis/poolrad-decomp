`src/recovered/overlay_u3b0_leaf_0067.c` models the DOS v1.3
`GAME.OVR` U3B0 `+0x0067..+0x00AA` body. This is a call-free leaf
reached by a decoded near call in the original overlay, but no natural
saved-game caller frame has been captured. Its game-routine identity and
strict full-C count remain **provisional**.

The caller pushes a far node head. The routine follows each node's next
far pointer at `ES:[DI+0x2A/+0x2C]`, increments a 16-bit count, and
returns that count in AX. A null head returns zero. The model preserves
the original stack locals, `OR` and `INC` flags, ES/DI effects, offset
arithmetic, and wrapped SP movement across `RETF 4`. A cyclic chain
does not terminate in the original; the finite parity cases do not
claim behavior for an infinite trace.
