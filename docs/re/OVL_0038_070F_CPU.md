# OVL_0038_070F: the 009E dispatcher's slot-21 handler (raw CPU, composing SYSTEM StrLoad, stopping at 00BA_16EC)

`pr_u38_070f_cpu_run` is a raw-CPU model of GAME.OVR unit `38h` `+070F` (full CPU14 + RAM state inside the composition
profile below): public entry 19 (stub `0041:007F`), the handler the `009E` dispatcher reaches through slot 21
(`DS:687C`), stored by the credited installer `OVL_0038_31A2` and listed as a named gap in
[OVL_009E_0000_HANDLERS.md](OVL_009E_0000_HANDLERS.md). It runs on flat RAM, composes the accepted SYSTEM StrLoad leaf
(`pr_system_strload_0b0b`), and **stops** at the far call to `RES_00BA_16EC` with saved state. This is a **bounded body
with one exact-call stop boundary**, not a strict full-C translation; it claims no identity, credit, accounting row or
dispatcher wiring.

## Behaviour

Entered after a far call: `[SP]` IP, `[SP+2]` CS, then five argument words. Only `[BP+0Ch]/[BP+0Eh]` (far pointer B)
are read; `[BP+6]` and the far pointer at `[BP+8]` are never read. `PUSH BP; MOV BP,SP; SUB SP,0Ch` makes a 12-byte
local L at `SS:BP-0Ch`. B and C (= the far pointer at `B+108h`) are reread with `LES` at every use.

1. **`CMP byte C+2, 0`; equal: step 4.**
2. Push B (segment, offset), push `SS:L`, push `CS:0703`; **`LCALL 0AF8:0B0B`**: StrLoad copies the 12-byte constant
   to L. Its accepted contract: `RETF 4` pops the source pair and leaves `SS:L` on the stack; `AL` := length `0Bh`,
   `CX` := 0, `DX` := DS, `BX` := its entry SP, `SI`/`DI` advanced, DF cleared, flags `XOR CH,CH`'s; AH is kept.
3. `AL` := `0Ah`, push `AX`; `AL` := 1, push `AX` (both high bytes carry the entry AH); **`LCALL 00BA:16EC`** with the
   frame 16EC's accepted header documents: wait byte 1, row byte `0Ah`, message `SS:L` ("is silenced"), and B's two
   words for its near 1816; `RETF 0Ch` balances the six words. **The model stops here: `STOP_16EC`.**
4. (Directly when `C+2` = 0; after 16EC otherwise, unreachable in this model.) `C+2` := 0; `C+1` := 0, B and C reread
   before each store. `MOV SP,BP; POP BP; RETF 0Ah`.

**Stop convention (saved partial state, no synthetic callee success).** `STOP_16EC` leaves the CPU exactly as the
`LCALL` left it: the return frame (CS, `0744`) pushed under the six argument words, CS the live word at `CS:0742`, IP
`16ECh`, BP this body's frame, L filled, `C+1`/`C+2` untouched. Nothing is rolled back. `diagnostic.callee` = 2 and
`diagnostic.site` = `073F`.

**Why 16EC is a stop and not a composition.** A merged bounded model exists, `pr_res_00ba_window_16ec_cpu`
([RES_00BA_16EC_CPU.md](RES_00BA_16EC_CPU.md)), but it runs on the `pr_bus` (EGA planes) with an environment of
display, printer, prompt, box and delay budgets, and its evidence records an intentional LIMIT difference from the
unbounded original; `RES_00BA_16EC` is also the still-open keystone (t24). Composing it would move this body to the bus
domain and import that whole closure. The saved stop state is exactly the entry state that model takes, so composing
it is a separate bounded step for the reviewer to authorize, not an improvisation here.

**Statuses.** `OK` (the `C+2` = 0 path); `ARGUMENT` (null pointers, RAM not 1 MiB, IP not `070Fh`; nothing changed,
diagnostic initialised -1/-1/0); `CALLEE` (StrLoad did not return: its status in `diagnostic.callee_status`; only its
own ARGUMENT exists, unreachable from here); `TRANSFER` (StrLoad returned elsewhere than `CS:0739`); `STOP_16EC`. No
limits parameter: StrLoad has no budget and this body has no backward branch.

## Composition profile

The state claim is full CPU14 + RAM **inside this profile**:

- The CPU and diagnostic objects are distinct from RAM.
- Loaded code and bindings are read live and immutable during the run: the constant `CS:0703..070E` and the segment
  words `CS:0737`/`CS:0742`. (The test shows both are read live, not baked in.)
- StrLoad's accepted contract applies to the copy: `REP MOVSB` byte by byte, `SI`/`DI` wrap at 16 bits, L and the
  source may alias; a longer string at `CS:0703` overruns L into the frame exactly as on the CPU (not exercised).
- 16EC's own entry precondition (SP in `[0800h,FFF0h]`) is **not** checked, because 16EC is not entered.
- Reached dependency return frames are nonwrapping; stack and data aliases stay live; no rollback on any stop.
- Interrupts, faults and self-modifying code are outside this synchronous profile.
- Flags: on the `OK` path the return flags are `CMP C+2,0`'s (ZF, PF); at `STOP_16EC` they are StrLoad's (`XOR CH,CH`:
  ZF, PF, DF clear). Deterministic conventions of the accepted models; no native equality implied.

## What is and is not claimed

- The 30 instructions, operand order, both call sites and fixups, the two constants and the single `RETF 0Ah` are
  measured from the bytes. The StrLoad composition reuses the merged leaf model unchanged.
- `RES_00BA_16EC` is an **unresolved dependency** for this body: exact-call stop with saved state. The post-16EC clears
  of `C+2`/`C+1` are emitted and reached only on the `C+2` = 0 path.
- No original-byte, Unicorn or DOSBox-X execution was run (not authorized at this stage). No row is added to
  `strict_full_c_addresses.csv`, `reviewed_function_identities.csv` or `partial_callee_models.csv`; slot 21 of
  `overlay_u9e_dispatch_0000_cpu.c` is untouched. The pre-existing `check_record_shas.py` failure (identities CSV commit
  ids absent from this clone) is unrelated.
