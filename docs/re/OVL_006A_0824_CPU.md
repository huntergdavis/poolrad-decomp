# OVL_006A +0824: raw-CPU model and original-byte differential for the 21-byte selection-exchange sort (evidence only; no credit proposed)

`OVL_006A_0824` (unit 0x6A, offset 0824h, no entry slot) sorts the 21 bytes at `G+17h .. G+2Bh`, where G is the far pointer at `DS:[5D92]`, into ascending order of their low seven bits. It is a leaf with no arguments and no callee.
**A complete C translation of this function is already on main** ([`U6A_SORT_0824.md`](U6A_SORT_0824.md), `overlay_u6a_sort_0824`, with a synthetic native gate in [`U6A_0824_NATIVE_FULLC_GATE.md`](U6A_0824_NATIVE_FULLC_GATE.md)). This change adds a **raw-CPU model**
(`overlay_u6a_0824_raw_cpu`, bus-aware, budgeted, with the same frame discipline as the other raw models), its checker, its native harness and this document, and it **cross-checks the merged translation against the original bytes on the same cases** (below). It proposes **no strict row, no identity row and no manifest row**, and it
**does not touch the blocker recorded for this row**: its one known call site is a single aligned `PUSH CS; CALL` in the uncredited `OVL_006A_090A`, and [`U6A_0824_NATIVE_REACH_BOUNDARY.md`](U6A_0824_NATIVE_REACH_BOUNDARY.md) records that no leaf entry was reached natively. Nothing here supplies that reached-caller capture.

## What the body does

Frame after the call: `[SP]` IP, `[SP+2]` CS. No arguments; plain `RETF`. Locals: `[BP-1]` = i, `[BP-2]` = j, `[BP-3]` = the swap temporary.

1. `PUSH BP; MOV BP,SP; SUB SP,4`; i := 0.
2. For i = 0 .. 13h (the loop ends when `CMP [BP-1],13h` is equal after the inner loop) and for j = i .. 14h: with `LES DI,[5D92]` **re-executed before every array access**, compare `(a[j] & 7F)` with `(a[i] & 7F)`; **if a[i]'s key is strictly above a[j]'s, swap the whole bytes** through `[BP-3]` and DL.
3. `MOV SP,BP; POP BP; RETF`.

The sort is not stable. Because the body keeps i, j and the temporary **in its own frame**, and re-reads G on every access, an array placed over that frame, over the saved BP and return address, or over G itself changes the loop, the return or the pointer: that is what the aliasing fixtures exercise.

## Role (identity is not claimed)

The role is a **sort of 21 bytes at offset 17h of the record addressed by `DS:[5D92]`**, ascending by the low seven bits with the high bits travelling with their bytes. The single known caller is the body at `+090A`, at `+0A4E`, which writes a byte at `G+17h` before the call. This note makes no claim about identity or about what the 21 bytes are: the two-factor test is the reviewer's.

### What pins the bus claim

Unicorn has no planar EGA, so the differential cannot see a model that bypasses the bus: **the two bypass mutants (array reads, array writes) survive the differential, as predicted, and each is caught by the C test**, which attaches an EGA: with the array at `A000:0100` and plane 0 holding 21..1 the sort reads plane 0 and writes all four planes, leaving 1..21 in every plane and the RAM bytes under the aperture untouched; without an EGA the same state is flat RAM. No native EGA run was made for this body.

### Mutation

**16 mutants, 16 caught: 14 by the differential and 2 by the C test.** Caught by the differential: the JBE ignoring ZF (equal keys swapped), the first comparison value not masked to seven bits, the array read at +16h, the outer loop ending at 14h, the inner loop ending at 13h, **the JA bound at 13h (caught by the flags at the `budget-7` arrival)**, the swap temporary not reloaded, G read from 5D94/5D96, the first loop counter starting at 1, `SUB SP,6`, **`INC BYTE` also setting CF (caught only by `found-inc-cf-1`)**, `XOR AH,AH` leaving AH, **AND/XOR setting AF (caught by `budget-12`)** and the return-address check dropped (caught by `array-at-bp-01`). The two mutants that make the array **read** and **write** bypass the bus survive the differential and are caught by the C test.
**The first mutation run left four mutants alive (13 of 17); the cause was an incomplete fixture set, and the fixtures above were added, not the mutants removed.** The mutation run now uses the 80-case budget sweep, four found fixtures and the other named cases.
**One mutant is equivalent and reported as such:** the JA ignoring ZF. `JA 0838` follows `CMP AL,14h`, so it differs only when AL = 14h at 0836. AL is the loop counter i, which is written only by the `MOV` at 082A (to 0) and the `INC` at 0830, and 0830 is reached only through 08B8, after `CMP [BP-1],13h / JE 08BB` fell through (i is not 13h). So i + 1 is never 14h at 0836, **whatever the array stores do**. It survived all 458 cases, consistent with the proof; the proof, not the survival, is the claim.

### Which way verdicts move under a convention split

**No case depends on the 16-bit-wrap-versus-contiguous convention for word accesses:** the array accesses are byte accesses (a byte offset wraps at 16 bits in both conventions), and the word reads (`LES DI,[5D92]`, the entry frame) are at a fixed address or inside the entry-SP bound. **No verdict moves.** A pointer in A0000..AFFFF moves a result from reproducible to not on a machine whose plane reads differ from flat bytes; the bus accesses are pinned by the C test and no differential case places the array there.
