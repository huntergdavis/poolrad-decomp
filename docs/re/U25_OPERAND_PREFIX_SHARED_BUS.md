# U25 operand-loader first prefix

`pr_u25_operand_start` and `pr_u25_operand_resume` extend the [SAVE-to-loader entry](U1C_SAVE_LOADER_ENTRY.md) on the same bus and CPU through the first two source operand bytes. Standalone `pr_u25_operand_prefix` begins at U25 `+0000`: it builds the live frame, initializes the string index, copies the low-byte operand count and compares it with one. Zero count stops at `+012C` before the loader's exit; a nonzero count initializes the live operand index, reads tag and value bytes through the current script far pointer, writes the source tag and value tables, updates the live script PC, and stops at `+005F` before the tag-specific branch. The source rereads PC, far pointer and local index in order; the wrapper retains these reads so stack and data aliases remain observable. No later loader or SAVE effects are fabricated. Earlier other-handler and prompt-loop boundaries remain distinct terminal outcomes.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 25 file base `74D3`. `[0000,005F)` is 95 bytes, SHA-256 `4d170209a0dc7e2295f2ac20a04d4b73fd3a87ab4ec825535bb9adb37a4c464e`. The existing [complete flat-RAM loader audit](U25_LOADER_0000.md) supplied prior evidence; the prefix was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `0000`, `SP` in `[000A,FFFA]`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session requires a 1C caller BP of at least 42 to keep this frame in profile and inherits earlier U68, 1C and provider requirements. Caller owns real code and bindings, immutable code outside EGA, writes avoiding code and nonwrapping reached return frames. Script-byte reads use the shared bus, including EGA latches and 16-bit effective-offset wrapping. The standalone bound only establishes this prefix; the complete flat-RAM loader's deeper frame and other requirements are separate. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up through synthetic opcode `09` to the first tag/value/PC updates, zero-count stop, wrapped EGA reads and INC flags, an index-local alias changing the second write, a first tag write aliasing the second script byte, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive. No original-runtime or native differential is claimed for this composition. Tag-specific paths, subsequent operands, loader and SAVE completion, later dispatcher/runner iterations, movement, visual parity, full gameplay and coverage credit remain unverified.
