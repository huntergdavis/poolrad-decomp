# Unit 0x25 +0x1684: provisional full-state public entry 13

`pr_u25_entry13_1684` translates the complete U25 public entry 13 (far stub
`2B:0061`) over caller-owned A20-off 1 MiB RAM and a fourteen-word CPU
frame. It composes its near callee `+156D` through the merged full-state
[`pr_u25_tilde_caps_156d`](U25_TILDE_CAPS_156D.md), forwarding that
routine's seven runtime calls to this routine's hook. Its five other
external callees are fail-closed call-site callbacks. **Game identity is
not asserted, and no strict full-C, identity, count or native credit is
requested.**

## Original boundary and ownership

Ignored DOS v1.3 `GAME.OVR` is 206,105 bytes, SHA-256
`872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`.
Unit `0x25` starts at file `0x74D3`. The routine is exactly file
`[0x8B57,0x8C5B)`, unit `+1684..+1787`, **260 bytes / 100 instructions**,
SHA-256 `1ba4ee097c797c4490a51228436ff10b3f389406b396b5fc06c066d5c67dd225`.
Its only return is `+1785 RETF 0x12`, and all jumps are internal.

The 32-byte set constant just before it, `+1664..+1683`, is its own. Its
`MOV DI,1664` at `+1717` is the only reference in the unit. The table is
not embedded here: the set-test hook reads it from caller RAM.

The callers are six far calls through `2B:0061`: U1C `+1232`, `+21DA` and
`+2633`, U1E `+0EAE`, U20 `+1135`, and U23 `+0714`. No source, branch or
sibling-clone file owned this interval at `c00f9d9`. It is disjoint from
pG's `+1DF0`/`+1EA6` and pF's `+0136`.

## Behavior

**Arguments.** Bytes a `[BP+6]`, enter flag `[BP+8]`, c `[BP+0xA]`, d
`[BP+0xC]` and e `[BP+0xE]`; far strings S2 `[BP+0x10]` and S1
`[BP+0x14]`.

**Frame** (`SUB SP,0x156`):

| Local | Contents |
| --- | --- |
| `[BP-0x2A]` | `string[40]` copy of S1 |
| `[BP-0x12A]` | `string[255]` copy of S2 |
| `[BP-0x153]` | hotkey string |
| `[BP-0x154]` | index |
| `[BP-0x155]` | key |
| `[BP-0x156]` | flag cell |
| `[BP-1]` | result |

**Setup.** StrStore copies S1 into `[BP-0x2A]` with cap `0x28` and S2
into `[BP-0x12A]` with cap `0xFF`. `+156D` then extracts the tilde hotkeys of
the S2 copy into `[BP-0x153]`.

**Input loop.** Each pass:

1. Call U3B0 entry 2. It receives the two locals, then e, d, c, the constant
   1 and a (as `MOV AL; PUSH AX`, so AH carries through), and a far pointer
   to the flag cell. Its AL becomes the key.
2. If the flag cell is nonzero: call U77 entry 10 with the key, then
   `BA:0767` with far `[5D94]:[5D92]`, then clear the key.
3. Test the key against the `CS:1664` set.
   - A member exits the loop.
   - A non-member that is not `0Dh` loops again.
   - `0Dh` loops again when the enter flag is zero, and exits otherwise.

The loop has no host cap and ends only on a terminating key, as in DOS.

**Result.**
- Key `0Dh` gives 0.
- Otherwise the hotkey string is scanned for the key from index 1. A
  match at position i gives i-1, computed with `DEC AX`; no match gives
  `FFh`.

The routine returns AL with `RETF 0x12`.

If `+156D`'s `RETF 8` resumes anywhere but `CS:16C2`, the routine reports
`PR_U25_1684_TRANSFER` with that CPU state.

**Source order and flags.** Every argument, local, global and set pointer
is re-read in source order. Flags are exact wherever a hook or the return
observes them:

| Observer | Flags it sees |
| --- | --- |
| First StrStore | `SUB SP` |
| Later callees | their predecessor's returned flags |
| U3B0 entry 2 | `+156D`'s flags on the first pass, then the `CMP key,0Dh` or `CMP [BP+8],0` that re-entered the loop |
| U77 | `CMP [BP-0x156],0` |
| Set test | the `BA:0767` flags, or that `CMP` |
| Return | `CMP 0Dh`, the scan `CMP`, or the `DEC` after `XOR AH,AH` (CF clear, AF from the borrow) |

## Verification

`test_overlay_u25_entry13_1684.c` uses a synthetic runtime with the decoded
SYSTEM effects. Both set tests read their tables from RAM, and a scripted
U3B0 key source drives the loop. It checks:

- the hotkey extraction and the eleven U3B0 argument words
- a looping non-member key, a first and a second hotkey, and a set member
  that is not a hotkey (`FFh`), each with its exact final flags
- Enter accepted, and Enter ignored when the flag is zero
- the flag-cell path through U77 and `BA:0767`, with the key cleared
- an abort at each of the first 15 calls
- TRANSFER
- argument rejection

It passes strict C11 `-Wall -Wextra -Wpedantic -Werror` and ASan+UBSan.

`check_overlay_u25_entry13_1684.py` pins:

- the body, `+156D` and StrStore hashes
- the six outer and seven `+156D` call sites with their targets
- the single near call and the unique `1664` reference
- the SYSTEM returns

Its source pins have run statically. Its Unicorn differential has **not**
run and waits for a PM serial slot. When run, it executes both routines'
original bytes over 94 cases:

- strings × key scripts × enter flags
- SS-alias and high-stack cases
- a `BA:0767` hook that rewrites `+1684`'s own return
- 30 seeded cases

For each case it compares all 1 MiB of RAM, the CPU words and every call
trace, and requires every instruction start and every conditional outcome.
Every scripted input loop ends on an upper-case set key.

No reached native `+1684` frame was searched. Callee and caller native
parity remain open.
