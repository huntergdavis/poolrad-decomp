# OVL_007F +0000: translated, evidenced far-pointer wrapper around resident 00BA:13AB (evidence only; no credit proposed)

This raw CPU body, `OVL_007F_0000` (unit 0x7F, offset 0, no entry slot), takes a far pointer, hands it to the resident far call `00BA:13AB`, and returns that call's result plus 05DCh. It was the only
unready callee of `OVL_007F_0054` and of `OVL_007F_044C`. This change adds the model, its checker, its native harness and this document. It proposes **no strict row, no identity row and no manifest row**; par-e accepts or refuses.

## Media and executable extent

The decoded span is **unit 0x7F [0000,0020), 32 bytes / 12 instructions**, GAME.OVR file offset 150,665, ending in the only return, `RETF 4` at 001D. Body SHA-256
`6801f21fb64d058573aaf8afc3174ca5bec2d870219cab7e8b8bb8f9ef46d6a2`. The span was taken from the GAME.OVR bytes. The checker asserts the hash and the 12 starts, **one far call (`000C LCALL 00BA:13AB`)**, no jump, near call, interrupt
or port instruction (**the body is straight line, so it has no conditional outcomes to account for**), the single `RETF 4`, and **exactly one relocation in the span, the segment word at `CS:000F`**. The model reads that word live on every call.

The resident closure the call reaches is **`00BA:13AB` [13AB,148B), 89 instructions, SHA-256 `22732f3c...b7bbe`, and the one body it calls, `00BA:11EA` [11EA,1282), 62 instructions, SHA-256 `8331051d...e020`** (full digests in the checker). The checker asserts
that 13AB's only call is the near call to 11EA and that neither body has a far call, port or interrupt. **Closure: 163 instruction starts** (12 + 89 + 62), all of them reached by the differential.

## What the body does

Frame after the far call: `[SP]` IP, `[SP+2]` CS, `[SP+4]` the pointer's **offset** word, `[SP+6]` its **segment** word. `RETF 4`.

1. `PUSH BP; MOV BP,SP; SUB SP,2` (flags as `SUB`).
2. Push `[BP+8]` (the segment), then `[BP+6]` (the offset); `LCALL 00BA:13AB`. The same far pointer goes through unchanged.
3. `ADD AX,05DCh` (flags as `ADD`), store to `[BP-2]`, load it back, `MOV SP,BP; POP BP; RETF 4`.

What the resident does with the pointer (read from the listing, pinned by the differential): `13AB` calls `11EA`, which reads the byte at `ES:[DI+10h]` and, for one range of that byte, the byte at `ES:[DI+16h]`, and maps them to a class byte; `13AB` maps
the class to a 16-bit value (an arithmetic table over class ranges). The wrapper's return value is that value plus 05DCh (1,500) in AX.

## Role (identity is not claimed)

The role is a **wrapper that returns a class-keyed value for a character record, offset by 1,500**: its subject is a far pointer to a record whose `+10h` and `+16h` bytes select the value. Measured ownership: **four near callers, all inside unit 0x7F** (the queue's
aligned PUSH CS callers: sites 0061 and 0080 in the body at 0054, 045D in the body at 044C, and 08C7 in the body at 063A), and no fixup-backed far caller. This note makes no claim about identity: the two-factor test is the reviewer's.

## Raw contract and stops

11EA 4 more, counted from the listing), so any entry SP of 1Eh or more would not wrap; 0040h leaves a margin, and the audit runs exactly at 0040h and at FFF0h. Each instruction of the body and of the resident closure consumes one unit of the budget; **LIMIT leaves the next unexecuted
instruction in `cpu->cs:ip`**. The resident segment is read live from `CS:000F`.

**The body dereferences no caller-supplied pointee.** Its one caller-supplied pointer reaches the resident helper, so **any exposure to the A0000..AFFFF aperture sits in the resident model's flat-RAM contract** (shared with `U9E_CHARACTER_PAIR_115C_CPU.md`), not in this body.
A pointer aimed into the aperture is outside that contract. **It is not built or demonstrated here:** Unicorn has no planar EGA, so a case there would compare flat bytes with flat bytes and prove nothing, and the native harness runs in the default machine, not an EGA one.
That is the same declared limit as in `OVL_0025_0341_CPU.md` and is listed again under Not established.

### Adversarial fixtures (a caller-supplied pointer inside memory the body and its callee create)

The body returns and frees nothing, so the analogue of "inside a block the body returns" is **inside the frames it and the resident callee push**:

- **`record-in-frame-00` .. `record-in-frame-23` (36 cases)**: the record is placed so that its `+10h` byte lands on each stack word from entry SP-6 down to SP-41, covering this body's pushed pointer words and its far-call return frame, 13AB's saved BP, local, pushed arguments and return frame, and 11EA's saved BP and local. The record bytes the resident reads are therefore words the callee chain has just pushed. (The entry frame itself, above SP, is covered by `record-over-args`.)
- **`record-over-args`**: the `+10h` byte lands on the pointer's own offset word in the entry frame.
- **`record-in-code-wrapper`, `record-in-code-resident`**: the record's `+10h` byte lands on the first code byte of the wrapper and of 13AB (the fixture installs code after the record, so code is never overwritten).
- **`rec-top-*` (40 cases)**: record offsets FFF0h to FFFEh with the `+10h` and `+16h` reads wrapping at the 64 KiB segment end, for five raw `+10h` values.
- **`record-FFFF:0200`, `record-FFF0:0010`, `record-0000:0000`, `record-AFFF:FFF0`**: the A20 wrap and the segment extremes. `record-A000:0100` is a flat-RAM case in Unicorn (see above).

All pass the full differential. Native runs seven frame placements and the top-of-segment case.

## Evidence

**Original-byte Unicorn differential on the composed closure: 861 cases, 0 mismatches.** The wrapper and the two resident bodies are the original bytes at their own segments; the resident segment word at `CS:000F` is the loader's relocation, and **the resident closure is placed at six different segments (7000h, 7345h, 0BA0h, A3C0h, FE00h, 1234h) and the body at three (6000h, 2345h, 9F00h)**, so a model that fixes the segment cannot pass. After every case, **unmasked**
(with the one declared exception below): CPU14 (dirty incoming flag words 0202, 0602, 0A87, 0402, 0E57, 08D7, 0893, 0003, 7202 are in the case set), **all 1,048,576 RAM bytes**, the stop, and the remaining budget.

Outcomes: **776 RETURNED, 85 LIMIT**. **Starts: 163/163** (the body 12/12). **Non-architectural stops: 0.**

Cases: all 256 raw `+10h` values; all 256 `+16h` values under raw kind 12h; six resident and three wrapper placements; eight entry SPs (0040h through FFF0h, odd values, 0101h); SS = DS and SS = the record's segment; ten flag images; record segments FFFFh, FFF0h, 0000h, A000h and AFFFh; the 36 frame cases and the seven special placements; **a 175-case budget sweep (0 to 174), whose first 85 stop the original at every instruction boundary of the whole path** (one raw kind, 12h with `+16h` = 20h); and 60 random cases (random registers, flags with TF excluded, record, resident segment and SP).

**The one declared exception (MUL):** MUL leaves SF, ZF, AF and PF undefined; the ADD that follows each of the three MULs overwrites them, so **no completed call exposes them**. A LIMIT stop on the very next instruction does, and Unicorn keeps the stale value where the model computes one. At exactly those arrivals the audit does not compare flag bits `00D4`; **1 arrival of the 861 cases was masked**, counted and reported. **The native run decides which side is right:** at the three MUL arrivals (`1430`, `144D`, `1475`) the real DOSBox-X result equals the model's, and at `144D` Unicorn differs from both (model 0206, Unicorn 0202).

### Mutation

**14 mutants; 13 caught, 1 survived and is equivalent.** Caught: the ADD constant (05DBh), the two pointer words pushed swapped, **the resident segment hard-coded instead of read live** (caught only by the non-default resident placements: at 7000h it is correct), the local store `[BP-2]` dropped, RETF popping 2 bytes, `SUB SP,4`, the ADD carry never set, the ADD auxiliary carry never set, the far call not charged to the budget, the call-offset check expecting 13ACh, the SP lower bound at 0050h, a resident LIMIT reported as CALLEE, and `MOV BP,SP` loading SP-2. The mutation run uses 13 of the cases and prints a START and a result line per mutant.
**The survivor: the return-address (TRANSFER) check dropped.** It is equivalent in the differential, and the reason is stated rather than assumed: the resident closure writes only at addresses below its own return slot (the saved BP, locals and pushes of 13AB and 11EA), and the record pointer is only ever read, so **no input makes the callee return anywhere but `0011`**. I tried to build the reaching state (the 36 frame placements put the record on every word the closure pushes) and none changes a return address, because the closure never writes above its frame. The C test cannot reach it either. The check stays in the model as a guard for a different resident implementation.

### Declared environment and substitutions

1. There are none that stand in for original behaviour: no stub, no INT 3Fh dispatch, no environment service. The resident closure is a pure RAM routine, so the whole call runs as original bytes in the oracle.
2. The resident models are the merged `pr_res00ba_helpers_cpu` family; this body adds one source file and its header. No existing checker was changed.
3. The Unicorn comparison treats the TF bit as outside the model: a single-step trap is an interrupt. The random flag words exclude it (a first run with TF set crashed Unicorn with a CPU exception; that is the reason, not a model finding).

## Not established

- **A record pointer in the A0000..AFFFF aperture:** outside the resident helper's flat-RAM contract; no case here covers it (Unicorn has no planar EGA; the native harness is not an EGA machine). **No differential case covers it and none passes there.**
- The TRANSFER stop and the C-side CODE stop in the differential: code is immutable and the resident closure writes only below its own return slot, so it cannot clobber its return address; both are exercised only by the C test (CODE) or not at all (TRANSFER).
- Real BIOS, DOS or EGA behaviour beyond the 47 native cases; the pinned DOSBox-X build.
- Natural reachability: the four callers are inside unit 0x7F; no saved-game or live-route measurement was made.
- Identity, credit and closure membership: the reviewer's.
- The prior-session memory tool (`deja`) was unavailable (it failed to connect with ENOENT); nothing was reused from earlier sessions. The 0341 and 115C audits were the templates, and every figure above was measured on this change.
