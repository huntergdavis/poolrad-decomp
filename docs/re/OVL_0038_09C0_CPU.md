# OVL_0038_09C0: the 009E dispatcher's slot-28 handler (raw CPU, a partial chain stopped at the 16EC window message)

`pr_u38_handler_09c0_cpu` is a raw-CPU, full-state model of GAME.OVR unit `38h` `+09C0`, the handler the `009E` dispatcher
reaches through slot 28 (`DS:6898`, stub `0041:0098`, public entry 24), stored by the credited installer `OVL_0038_31A2`
([OVL_009E_0000_HANDLERS.md](OVL_009E_0000_HANDLERS.md) lists it as a named gap). It runs on flat RAM, as the dispatcher's
handlers do, and composes the credited unit `9E` entry-8 roll (through its loaded stub), the credited unit `38h` helper
`+0000`, the SYSTEM string load `0AF8:0B0B`, and the partial unit `9E` `+0026` list-node removal (through its loaded stub).

**Claim, stated narrowly.** This change supplies a body, its test, a static checker and this document. It is a **partial
chain**: the resident window message `RES_00BA_16EC` is recorded as **not closable on the currently recorded evidence**
([RES_00BA_16EC_CLOSURE_STATUS.md](RES_00BA_16EC_CLOSURE_STATUS.md); keystone t24), so the body stops before its call
with the exact state saved. Its bus-based model (`resident_00ba_window_16ec_cpu.h`, EGA display closure) is not pulled
into this flat handler. **It is not a strict full-C port, proposes no credit, and flips no dispatcher slot** (slot 28 stays
a named gap in `overlay_u9e_dispatch_0000_cpu.c`). No original or native execution was run: the checker reads the media as
bytes only. Task t492 (the queued successor of t491; no evidence is borrowed from that chain: every fact below was re-derived
from the bytes); reviewer reserved through the CoS.

## Behaviour

Frame after the far call: `[SP]` IP, `[SP+2]` CS; `[BP+6]` a byte, **unused**; `[BP+8]` a far pointer A, a record whose
byte `+3` is a counter; `[BP+0Ch]` a far pointer B. `SUB SP,0Eh` makes one local, `[BP-0Eh]`, a 14-byte string buffer.
AH is never cleared before the `01h`, `00h`, `0Ah` and `01h` pushes (`XOR AH,AH` precedes only the range), so each callee
sees the live AH in its word argument.

1. **Roll.** Push `AH:01h` (the count, `[BP+8]` of the roll), then `AX := zero-extended A+3, plus 1` (the range, `[BP+6]`);
   `LCALL 00B0:0048` through the loaded stub of unit `9E` entry 8: the model reads the five stub bytes at the live segment
   word `CS:09D7`, offset `0048`, and requires `EAh`, offset `0DE3` **before anything is pushed** (`CODE` otherwise, IP
   `09D4`), as the dispatcher model does for its own stubs. The credited roll `pr_u9e_entry8_fullstate_compose_0de3`
   ([U9E_ENTRY8_ROLL.md](U9E_ENTRY8_ROLL.md)) runs at the stub's target segment and returns AL (`RETF 4`). `CMP AL,1; JBE`:
   a roll of at most 1 returns (a range byte of 0, from `A+3 = FFh`, yields 1).
2. **Gates.** `DS:681B = 0` returns; `DS:6820 <> 0` returns.
3. **Message.** Push `AH:00h`; `PUSH CS; CALL +0000`: the credited helper `pr_u38_helper_0000_cpu`
   ([U38_HELPER_CLUSTER_CPU.md](U38_HELPER_CLUSTER_CPU.md)) with key 0 clears `DS:6818` and `DS:6817`, `RETF 2`. Push B
   and `SS:BP-0Eh`; `0AF8:0B0B` (StrLoad, [SYSTEM_STRING_LEAVES.md](SYSTEM_STRING_LEAVES.md)) copies the string at
   `CS:09B2` into the buffer and pops only its source (`RETF 4`); push `AH:0Ah` and `AH:01h`; then `+0A0D LCALL 00BA:16EC`.
   **The model stops here (`PENDING`)**: IP `0A0D`, the six argument words (B, the buffer pointer, `0Ah`, 1) pushed and
   nothing pushed for the call, the buffer holding the copied string, `DS:6817/6818` cleared, `A+3` unchanged.
4. **Not completed paths** (after the stop): 16EC's effects (`RETF 0Ch`), `A+3 := A+3 - 1`, the return when the new `A+3`
   is nonzero, the `LCALL 00B0:002A` (unit `9E` `+0026` with a nil item and type `1Ch`, composed through its checked stub
   exactly as in `OVL_0038_0775_CPU.md`, its stops surfacing as `CALLEE`), `MOV SP,BP; POP BP; RETF 0Ah`. The generated
   cases for them are exact but **no test world reaches them**; OK is reachable only through the three early returns.

**Statuses.** `OK`, `ARGUMENT` (null RAM, CPU or limits, RAM not 1 MiB, IP not `09C0h`; nothing changed), `CODE` (either
stub), `CALLEE` (the roll's `LIMIT` on a zero SYSTEM-call cap, or any non-returned status of the roll, the helper, StrLoad
or `+0026`, with the callee's status and the state as it left it), `TRANSFER` and `PENDING` (`+0A0D`). `limits` carries the
roll's SYSTEM-call cap and `+0026`'s caps; the diagnostic names the last callee (1 = roll, 2 = helper, 3 = StrLoad, 4 = the
16EC stop, 5 = `+0026`), its status and the site.

## Validation

**Focused C test.** `test_overlay_u38_handler_09c0_cpu.c` passes **479** hand-predicted checks, built with asserts on, on
synthetic RAM with no game bytes (the four relocated segment words, the loaded-stub forms of unit `9E` entries 8 and 2, the
shared dice fixture's `+0E0E` call site, multiplier word and seed, a 5-character synthetic source string at `CS:09B2`,
synthetic records and DS bytes). It covers: the forced roll of 1 for `A+3 = 0` and for `A+3 = FFh` (range byte 0), with the
count word carrying the entry AH and the seed advanced; a 1d100 over 64 seeds matching the fixture's generator, returning
at the `DS:681B` gate; the `DS:6820` gate over the same seeds; the full path to the `+0A0D` stop with the stack frame, the
copied string, StrLoad's exit registers, the cleared `DS:6817/6818` and the untouched `A+3`; the roll stub refused as
`CODE` on a wrong opcode and on a wrong offset with nothing pushed for the call and the seed untouched; the roll's `LIMIT`
at its nested call surfaced as `CALLEE`; an A offset that wraps at 16 bits; a run without a diagnostic; every `ARGUMENT`
case with the CPU unchanged; and a sweep that the world writes nothing outside its declared bytes.

**Static checker.** `tools/overlay/ovl038_09c0_cpu_audit.py` (`CHECKER_ROWS = ('OVL_0038_09C0',)`) proves every row of the
"Exact original" table from the pinned media read as bytes, including that the whole bound is code, the five calls in
order, the four fixups and no other in the string or the span, the four jumps, the two DS tests, the decrement, the string
and both unit `9E` bindings, and that the emitter regenerates the committed C byte for byte. `--compile-only` builds the
model with its thirteen composed sources and binds the symbol with no media (`CHECKER_BUILD_OK`). The report says
`executed: false`.
