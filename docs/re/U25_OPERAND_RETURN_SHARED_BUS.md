# U25 operand loader return on the shared bus

`pr_u25_operand_return` continues the numeric or zero-count loader exit at `+012C`: increment the word at DS:49ED, restore SP and BP from the live frame, and execute the far return with two-byte argument cleanup. It checks the resulting CS, IP, SP, BP and SS against a caller-supplied target. A mismatch reports a transfer after the source effects, rather than undoing them. The counter write precedes all frame reads, so a counter aliased to a saved frame word changes the live return.

`pr_u25_return_start` and `pr_u25_return_resume` compose the [bounded numeric loop](U25_NUMERIC_LOOP_SHARED_BUS.md) through this exit and check the SAVE continuation at `+02A0`. The expected frame derives from the copied outer U1C target and the source call frames. String, budget, prompt and other stops remain distinct; the zero-count path reaches the exit only when its nested diagnostic identifies that path. A suspended session retains the earlier CPU integrity checks and copied targets.

The existing [U25 loader audit](U25_LOADER_0000.md) records the increment and `RETF 2` for pinned GAME.OVR SHA-256 `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`. Standalone entry requires IP `012C`, BP in `[0008,FFF8]`, SP=BP-8, exactly 1 MiB RAM, attached EGA, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed path inherits the prior profiles, bounds and caller responsibilities, including immutable code and valid reached frames. These are bounded assumptions, not a general alias or hardware proof.

Synthetic tests cover the idle-to-Up two-numeric-operand route through SAVE return, the zero-count prefix and return, a counter/return-address alias, counter wrap and carry preservation, and invalid-frame atomicity. The fixture and wrapper pass strict-warning ASan/UBSan with the provider archive uninstrumented. No original-runtime or native differential is claimed. String execution, later SAVE effects, movement, visual parity, full gameplay and coverage credit remain unverified.
