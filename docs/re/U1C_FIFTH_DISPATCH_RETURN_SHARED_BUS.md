# Fifth SAVE dispatcher return

`pr_fifth_dispatch_return_start` and `pr_fifth_dispatch_return_resume` extend the [fifth SAVE handler return](U1C_FIFTH_HANDLER_RETURN_SHARED_BUS.md) through the existing [dispatcher return](U1C_SAVE_DISPATCH_RETURN_SHARED_BUS.md). The helper reads the live frame on the shared bus and performs the checked return to runner `+31A8`; its expected target is derived and copied from the outer frame at start. Earlier fifth-store and other outcomes pass through unchanged. A mismatched live return stops after executed effects. This composition reuses [fourth SAVE dispatcher return](U1C_FOURTH_DISPATCH_RETURN_SHARED_BUS.md).

Start rejects outer BP below 56 or any nonempty nested handler, store-return, low, dispatch, classifier-return, classifier, store, value, pair-return, pair, slot, branch, loader, SAVE, dispatcher or runner before mutation. It inherits earlier frame, budget, code and caller requirements. These are bounded assumptions, not a general alias or hardware proof. No original bytes are embedded.

Synthetic integration covers the idle-to-Up fifth low no-op route through the checked runner return, copied target, a fifth later opcode, earlier stops, and atomic rejection and retry for each nested phase and invalid BP. Existing standalone tests cover mismatched returns; fifth-route writes and most earlier stop mappings are not separately driven here. The wrapper and fixture pass strict-warning ASan/UBSan with the provider archive uninstrumented. No native differential, runner continuation, movement, visual parity, full gameplay or coverage credit is claimed.
