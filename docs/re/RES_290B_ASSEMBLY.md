# U68 to 290B string assembly

`pr_u68_290b_assembly_start` and `pr_u68_290b_assembly_resume` extend the [record branch](RES_290B_RECORD_BRANCH.md) on the same bus and CPU through `00BA:2ACD`. Standalone `pr_290b_assembly` starts at `+2A51`. Two source-ordered passes use the real guarded `0B0B`, `0B98`, and `0B25` leaves. The first reads the live byte `DS:6AAF`, forms `DS:(25A8 + 3*byte)` with source 16-bit arithmetic and adds the caller-owned `CS:28F6` literal. The second appends the existing first and second field locals and caller-owned `CS:28F8` literal. Calls and return frames are checked at each reached site; earlier writes and partial stops remain visible.

The pinned START.EXE SHA-256 is `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`. Loader-expanded `00BA:[2A51,2ACD)` is 124 bytes with SHA-256 `b817237ce58937b3c558f4d3dfbf119668f6fc558bf54673a3a0235ca8d1b674`. The earlier [290B audit](RESIDENT_ROUTE_290B.md) identified these calls; the span was independently decoded against the pinned executable. No game bytes, table values or literals are embedded.

Standalone entry requires the existing 290B frame (`BP` in `[043C,FFEE]`, `SP=BP-0232h`), exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. Each live segment passed to a flat string leaf is checked by the existing guard at the reached call. Caller-owned code, relocations, table, literals and prior locals are required. This is a bounded profile, not general EGA support for string leaves.

Synthetic tests cover idle-to-Up through both assembly passes, the maximal index and its arithmetic flags at a malformed call, a first-leaf write aliasing the subsequently read index, invalid-frame atomicity, and a second-pass malformed call retaining the first stored string. The wrapper and fixture passed strict-warning ASan/UBSan linked to the existing provider archive. They do not establish original-runtime or native differential parity. `+2ACD` precedes the mode-dependent branch, display and U68 return; no full display, gameplay or coverage credit is claimed.
