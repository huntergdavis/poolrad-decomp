# OVL_0033 +0B97: translated, evidenced two-cell grid store and counter increment (evidence only; no credit proposed)

This raw CPU body, `OVL_0033_0B97` (unit 0x33, offset 0B97h, no entry slot), is a leaf with three arguments: a near pointer P, a byte X and a byte Y. It reads the far pointer G at `DS:[6716]`, stores 34h at `G + Y*50 + X + 7` and 35h at the next byte, then
increments the byte at `SS:[P-2]`. X and Y are **signed** bytes. It calls nothing, so there is no callee closure to compose. This change adds the model, its checker, its native harness and this document. It proposes **no strict row, no identity row and no manifest row**; par-e accepts or refuses.

## Media and executable extent

START.EXE SHA-256 d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd; GAME.OVR SHA-256 872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614.

The decoded span is **unit 0x33 [0B97,0BDE), 71 bytes / 29 instructions**, GAME.OVR file offset 53,608, ending in the only return, `RETF 6` at 0BDB. Body SHA-256 `75c464f3df7839fc6a44ab167138b0addb4a329758a775b3255c50a35108b52a`. The span was taken from the GAME.OVR bytes. The checker asserts the hash and the 29 starts,
**no jump, call, interrupt or port instruction (a straight-line leaf, so it has no conditional outcomes to account for)**, the two `MUL` instructions (at 0BA7 and 0BC4), the single `RETF 6`, and **no relocation in the span**.

## What the body does

Frame after the call: `[SP]` IP, `[SP+2]` CS, `[SP+4]` P (a near pointer, an offset in SS), `[SP+6]` X, `[SP+8]` Y (each a word slot whose **low byte** is read; the high byte is ignored). `RETF 6`.

1. `PUSH BP; MOV BP,SP`.
2. `CX := signed X`; `AX := signed Y`; `DX := 0032h; MUL DX` (DX:AX := AX x 50, AX taken as the unsigned 16-bit value of the sign-extended Y); `LES DI,[6716]`; `DI := DI + AX + CX` (16-bit); `ES:[DI+7] := 34h`.
3. The same again with **X and Y re-read from the frame** (X + 1 this time, via `INC AX`): `DI := G + Y*50 + (X+1)`; `ES:[DI+7] := 35h`.
4. `DI := [BP+6]` (P is **read after both stores**); `INC BYTE SS:[DI-2]`; `POP BP; RETF 6`.

The body creates no pointee of its own except its frame, and it stores three times through pointers it did not create. **Its frame is reachable by those stores**: the saved BP, the return address, P, X and Y sit directly above `BP`, and the second half re-reads X and Y after the first store.

## Role (identity is not claimed)

The role is a **two-cell tile store into a table whose rows are 50 bytes apart, with a counter increment in the caller's frame**: it writes 34h and 35h into two adjacent bytes at column X, row Y (offset +7 into the cell) of the table at `DS:[6716]`, and bumps a byte its caller points at. Measured ownership: **three near callers, all inside unit 0x33** (sites 0CB6, 0CFB and 0D0C in the body at 0BDE) and no fixup-backed caller; **no queue row has it as a callee**. This note makes no claim about identity: the two-factor test is the reviewer's.

## Pointer census

Every pointer the body dereferences that it did not create, and whether the access goes through the bus (`pr_bus`: with an EGA attached, a byte access to A0000..AFFFF goes to the planes):

| P, the near pointer `[BP+6]` | the caller's frame | the **word is read flat**; the byte at `SS:[P-2]` is **read, incremented and written** | the word: no, flat SS; **the read-modify-write: yes, through the bus** |

**The body dereferences caller-supplied pointers three times, so all three accesses go through the bus.** There is no callee, so there is no second place for an aperture exposure to sit: the whole exposure is in these three accesses.

### What pins the bus claim

Unicorn has no planar EGA, so the differential cannot see a model that bypasses the bus: **three of the 17 mutants (each of the three accesses bypassing the bus) survive the differential, as predicted**. The claim is pinned by the **C test, which attaches an EGA** and predicts by hand: a grid store at `A000:0100` writes `34h`/`35h` to **all four planes** at 0100h and 0101h and leaves the RAM bytes untouched (the same state without an EGA writes the RAM);
and with the stack segment in the aperture (`SS = A000`) the counter increment reads plane 0 (`20h`) and writes `21h` to all four planes. **All three bypass mutants are caught by that test.** No native EGA run was made for this body.

### Adversarial fixtures (a caller-supplied pointer placed on the memory the body itself creates)

- **`near-ptr-at-bp-10 .. +13` (36 cases)**: the counter byte `SS:[P-2]` on each byte from `BP-10h` to `BP+13h`: the unused area below the frame, the saved BP's low and high bytes (so the restored BP changes), **the return IP and CS (so the return transfers elsewhere; 4 TRANSFER cases)**, P itself, X, Y and the caller's words above them.
- **`grid-at-bp-10 .. +13` (36 cases)**: the first store (34h) on each of those bytes, the second (35h) on the next. **The stores clobber the saved BP, the return address (5 TRANSFER cases) and the arguments.**
- **`grid-args-bp+06..+0b` (12 cases)**: the first store on P, X or Y themselves (for two (X,Y) pairs): **the second half re-reads X and Y after the first store, so it computes with the clobbered byte**, and **P is read after both stores**, so the counter increments through the clobbered pointer.
- **`both-bp*` (14 cases)**: the grid cell and the counter on the same frame byte (and on neighbouring bytes), with six TRANSFER cases.
- **`grid-is-counter`, `grid-over-globals`, `grid-over-globals-seg`**: a store on the counter byte, and the first store on G's own offset word and segment word (the second half re-reads G through `LES`).

All pass the full differential. Native runs a safe subset: the counter and the first store on the saved BP, the pointer words and the arguments (never the return address, which cannot return to the oracle program).

**The one declared exception (MUL):** MUL leaves SF, ZF, AF and PF undefined until the next instruction that writes the flags, so the arrival on each instruction from the one after a MUL up to and including that writer holds a stale value in Unicorn where the model computes one. **At exactly those arrivals (0BA9, 0BAD, 0BC6, 0BCA) the audit does not compare flag bits `00D4`**; **4 arrivals of the 820 cases were masked**, counted and reported. (The merged `+0000` and `+0054` audits mask only the arrival immediately after a MUL, which is all their code needs, because an ADD follows it directly.) ### Mutation

**17 mutants, 17 caught: 14 by the Unicorn differential and 3 by the C test.** Caught by the differential: the multiplier 33h, the first store at +6, the two values swapped, **X zero-extended instead of sign-extended (caught by X = 80h)**, **Y zero-extended (caught by Y = 80h)**, the second cell not advanced (`INC AX` dropped), the counter decremented, the counter at P-1, `INC BYTE` also setting CF, RETF popping 4 bytes, **the return-address (TRANSFER) check dropped (caught by `near-ptr-at-bp+02`: the model returns RETURNED where the original transfers)**, the globals read at 6718/671A, the MULs not charged to the budget, and MUL leaving CF and OF clear (caught at the budget-9 arrival, where CF and OF are compared).
**The three bus-bypass mutants (the first grid store, the second grid store and the counter increment, each written or read as flat RAM) survive the differential, as predicted, and each is caught by the C test**, which attaches an EGA. Nothing in the differential can see them, because Unicorn has no planar EGA; this is why the bus claim names the C test and not the differential. The mutation run uses 23 of the cases, prints a START and a result line per mutant. **One first-version mutant did not compile** (the INC AX one left a helper unused under `-Werror`); it was rewritten to keep the helper referenced and is not counted as a catch.

### Declared environment and substitutions

1. There are none that stand in for original behaviour: no stub, no INT 3Fh dispatch, no environment service, no callee. The whole body runs as original bytes in the oracle.
2. TF is excluded from the random flag words (a single-step trap is an interrupt, outside this model), and FLAGS bit 1 is always set (the machine reads it as 1).

### Native corroboration (partial; packaged DOSBox-X, not the pinned build)

Not native: the TRANSFER cases, the budget sweep and the aperture. Frames are synthetic; this does not establish natural reachability.

### Which way verdicts move under a convention split

**No case depends on the 16-bit-wrap-versus-contiguous convention for word accesses:** the three stores and the increment are byte accesses (a byte offset wraps at 16 bits in both conventions), and the word reads (`LES DI,[6716]` and `MOV DI,[BP+6]`) are at a fixed address or inside the entry-SP bound, never at offset FFFFh. **No verdict moves.** A pointer in A0000..AFFFF moves a result from reproducible to not on a machine whose plane reads differ from flat bytes: the three bus accesses are pinned by the C test, and no differential case places a pointer there.

## Not established
