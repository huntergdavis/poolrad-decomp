# U68 through 290B printer and checked return

`pr_u68_290b_print_start` and `pr_u68_290b_print_resume` extend the [rectangle clear path](RES_290B_CLEAR.md) through real `0709:0626` printing and the 290B epilogue on the same bus and CPU. Standalone `pr_290b_print_return` begins at `00BA:2B47`: it preserves AH while pushing source byte arguments, passes the live local string, validates the reached `+2B55` far call, reads its segment after the call-frame pushes, and invokes the existing printer with caller-supplied outer/glyph budgets. It checks the printer return to `+2B5A`, executes `MOV SP,BP; POP BP; RETF` using live bus words, then checks the resulting CS, IP, SP, BP and SS against an explicit target. The composed session captures the U68 entry CS, BP, SP and SS and expects IP `0BA0`. Unexpected returns expose the actual state as a transfer stop; nested stops preserve prior CPU, RAM and EGA effects.

Pinned START.EXE SHA-256 is `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`; loader-expanded `00BA:[2B47,2B5E)` is 23 bytes, SHA-256 `d0fe328acbfc839860c35e8abe5679fc5c263e1d87ae7f05ca25d5cc30546f0a`. The earlier [290B audit](RESIDENT_ROUTE_290B.md), [printer provider contract](RES_0709_PRINTER_0626_CPU.md), and U3B0 clock/draw printer integration supplied the prior evidence; the call and epilogue were independently decoded from the pinned executable. No game bytes are embedded.

Standalone entry requires the existing 290B frame (`BP` in `[043C,FFEE]`, `SP=BP-0232h`), exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The reached printer code segment must also be ordinary. The caller owns real loaded code and bindings, immutable code outside EGA, writes that avoid code, nonwrapping reached return frames and the printer provider's documented bus, callback and hardware profile. If a successful printer changes BP above `FFFA`, the wrapper stops before the epilogue as a profile limit. These are bounded preconditions, not a general proof of all aliases or video modes. Both clear and printer budgets are copied into the composed session; nested stops are terminal.

Synthetic tests exercise idle-to-Up through real clear and printer to checked U68 return, an EGA plane byte changed by the printer, a modified live return word, malformed call, nonordinary printer segment, printer loop exhaustion, copied session budgets, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked to the existing provider archive. These tests do not establish original-runtime or native differential parity. Reaching U68 `0BA0` does not establish the rest of U68, full gameplay, visual parity, or coverage credit.
