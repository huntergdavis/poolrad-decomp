# Resident 0802:0000, the FreeMem wrapper: raw CPU, composed (t30 side ii)

`pr_r0802_0000` (`src/recovered/resident_0802_0000_cpu.c`) is the raw-CPU, full-state model of START.EXE resident
`0802:[0000,0020)`, the heap-release wrapper that 0716 calls at +0941 (FREE) for the packed-block buffer. It is one of t30's
side (ii) bodies. Its seam FREE@0941 is the last of 0716's seven stop sites to get a model.

**A body and its evidence; never a credit.** It is proposed for the `resident_runtime` never-credit class
([RESIDENT_RUNTIME_CLASS.md](RESIDENT_RUNTIME_CLASS.md)). Its subject is the heap. The membership row is proposed below as
text, for par-e to accept.

## Behaviour

    0000 PUSH BP; MOV BP,SP
    0003 LES DI,[BP+8]; PUSH ES:[DI+2]; PUSH ES:[DI]     (the pointer VALUE; the variable itself is not cleared)
    000D AX := ([BP+6] + 7) AND FFF8h                    (the size rounded up to an 8-byte granule, in 16 bits)
    0016 PUSH AX; LCALL 0AF8:0254 (FreeMem)
    001C POP BP; RETF 6

- **Narrow value (the same 16-bit rounding as 0020, the other half of cluster instance 7).** A size of FFF9h–FFFFh wraps to
  a 0-byte request. FreeMem's size-0 path is a **no-op with no pointer check**, so the release is **silently skipped**: a
  leak, and no RunError even for a bogus pointer.
  - Catchers: the independent statement (`wrap-fff9-bogus-pointer`, `wrap-ffff-valid-pointer`); the C test; native.
- **The pointer variable is not cleared.** The wrapper passes the pointer's value and never writes the variable, so a
  dangling pointer stays in the caller's variable. The statement asserts it in every checked case.
- **Through 0716** the call at 0941 passes `[BP-2Ch]` and `DS:557E`, the same packed size and variable that 0020 allocated
  with at 08B3–08BC (decode). That is after the 8CA0h guard, so the wrap is unreachable there as well.

## Composition and contract

- **Composed:** FreeMem `0AF8:0254` (`system_freemem_0254_cpu`, a runtime-covered endpoint). Its segment word is read live,
  and it must return to 001Ch, otherwise the stop is **CALLEE**.
- **FreeMem's stops pass through:**
  - **RUNERROR:** a pointer whose offset is not 0 or 8, outside `[HeapOrg, HeapPtr)`, or a duplicate; AX = 204 at
    `0AF8:00E2`; non-returning.
  - **LIMIT:** the declared `max_steps` cap on FreeMem's free-list walk.
- No DOS service.
- Exactly 1 MiB of RAM with the relocated code at CS. IP = 0000h; entry SP in `[002Ch,FFF6h]`.
  - FreeMem's own entry SP, 12 bytes lower, must lie in its declared `[0020h,FFF6h]`.
