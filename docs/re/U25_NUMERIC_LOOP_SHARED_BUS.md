# U25 numeric operand loop

`pr_u25_loop_start` and `pr_u25_loop_resume` extend the [first tag branch](U25_OPERAND_TAG_SHARED_BUS.md) on the same bus and CPU through bounded numeric operand iterations. Standalone `pr_u25_numeric_loop` begins at `+0121`, rereads the live local index and count, and stops at `+012C` if equal. Otherwise it takes the source back edge to `+001F`, increments the live byte index, runs the existing source-ordered two-byte operand iteration and tag branch, and repeats. String tags stop at their existing `+009A` or `+00D7` boundaries before string effects. Earlier prompt, other-handler and zero-count boundaries remain distinct. The existing first-operand implementation and the loop share the same iteration body; no subsequent string or loader-epilogue effects are fabricated.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 25 file base `74D3`. `[001F,005F)` is 64 bytes, SHA-256 `72d49fc2188f65703f0ef6d4ef2efb1efd95b57726937b420f35e2a9c6bbdee4`; `[0121,012C)` is 11 bytes, SHA-256 `eba4956ab8388a78ec2e719b881315107952b94799e34de84b0c1a3e025c1fac`. The existing [complete flat-RAM loader audit](U25_LOADER_0000.md) supplied prior evidence; the loop was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `0121`, `BP` in `[0008,FFF8]`, `SP=BP-8`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session inherits earlier U68, 1C, SAVE and loader profiles. Caller owns real code and bindings, immutable code outside EGA, writes avoiding code and nonwrapping reached return frames. Script reads use the shared bus, including EGA latches and 16-bit offset wrapping. `max_iterations` counts executed `+001F` back edges after the first operand; if exhausted, the wrapper stops at `+001F` after the live comparison and before the increment. A zero budget still permits an already-equal exit. Budgets are copied into the composed session and do not claim source termination. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up through two numeric operands, exact and exhausted budgets, later string stop, EGA third-byte read/latches, byte-index wrap, a PC/index alias that prevents normal termination, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive. No original-runtime or native differential is claimed for this composition. String paths, loader epilogue and SAVE completion, later dispatcher/runner iterations, movement, visual parity, full gameplay and coverage credit remain unverified.
