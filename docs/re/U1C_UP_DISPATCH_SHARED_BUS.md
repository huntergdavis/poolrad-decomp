# Unit 1C window and key dispatch

`pr_u1c_dispatch_start` and `pr_u1c_dispatch_resume` extend the [post-Up caller path](U1C_POST_UP_SHARED_BUS.md) on the same bus and CPU through the window/key dispatch. Standalone `pr_u1c_dispatch` starts at `+33BD`, with ES:DI already loaded by the preceding slice. It reads window-1 word `ES:[DI+0594]` through the bus and performs the source unsigned comparison. The real `0AF8:182A` upcase leaf is invoked at each reached site with its actual argument and far return frame; the live `DS:49FF` gate is read only where reached. Successful source branches stop at `+344C`, `+33EC`, or `+33E6` before the search call. Reached call checks, return transfers and prior effects are retained.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. `[33BD,33E6)` is 41 bytes, SHA-256 `3a2abea16a683dd3814eea73bbd2abad986584a98cb6efe2030d2af6cb0f095c`. The earlier [U1C loop audit](U1C_LOOP_3387.md) and the existing [SYSTEM runtime leaves](SYSTEM_RUNTIME_LEAVES.md) supplied prior evidence; this span was independently decoded from the pinned overlay. No original bytes are embedded.

Standalone entry requires IP `33BD`, `BP>=8`, `SP=BP-2`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. An effective window word offset `FFFF` stops before the read at `+33BD`; other reads use the shared bus including EGA latches. Each reached upcase call requires an ordinary live code segment because its provider uses flat RAM. Caller owns real code and bindings, immutable code outside EGA, writes avoiding code and nonwrapping return frames. The composed session requires the earlier U68/1C and provider profiles. This is a bounded profile, not general alias or hardware proof.

Synthetic tests exercise idle-to-Up, all three branch boundaries, both upcase sites, EGA read and latches, word-wrap and malformed/profile stops, invalid-frame atomicity, copied target, suspended CPU tampering, and a call-frame write aliasing the later `49FF` gate. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive. No original-runtime or native differential is claimed. Search, scripts, later movement, visual parity, full gameplay and coverage credit remain outside this slice.
