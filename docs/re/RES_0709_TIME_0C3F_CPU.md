# Resident 0709:0C3F bounded clock provider

`pr_r0709_time_0c3f_cpu` models START.EXE `0709:[0C3F,0CAB)`, 108 bytes and 48 instructions, ending in RETF. This is a bounded provider, not a coverage credit, gameplay integration, or native parity claim. The loader-expanded body has SHA-256 `a8e33767ba204b74a7c909cb85a7580ddbbaa36d60dfafb5fb3425d8c16412ed` and is byte-identical to `08AE:[0000,006C)`. Its two far calls are at `0C59` and `0C69`, with live segment words at `0C5C` and `0C6C`; true return offsets are `0C5E` and `0C6E`. The generator checks this identity against the private owner executable and emits each instruction at its 0709 offset using the established 08AE template.

The clock composes the existing DOS GetTime and SYSTEM LongMul models. For arithmetic, including the original's low-word truncation of minute multiplication, see [the 08AE clock evidence](RES_08AE_TIME_0000_CPU.md). The DOS INT 21h service is supplied by the caller and must follow its existing no-RAM-write contract. The caller must also leave the bus and EGA attachment unchanged during the service. Original instruction bytes and call offsets are immutable; segment operands are read live. The caller provides the loaded and relocated code, stack, and return frame.

The new entry accepts an attached EGA but its flat-RAM leaf models cannot safely access the aperture. Before execution it rejects any EGA overlap by either byte of every potential word in the conservative `SS:(entry SP-2Eh .. entry SP+3)` footprint, accounting for 16-bit offset and 20-bit physical wrapping. This covers the constructed arguments, locals, leaf frames and caller return. On rejection CPU, RAM, EGA and diagnostic are untouched. This is deliberately narrower than blanket alias safety. Code segment operands remain bus reads and can themselves hit EGA, including their ordered latch effects. Without EGA the same footprint restriction is unnecessary. GetTime's own frame guard and refusal contract remain in force; a refusal stops inside GetTime with prior pushes and the actual return offset preserved. Other stops and diagnostic numbering use the existing 08AE types. The service must not change RAM, so the four internally constructed GetTime pointers remain within the guarded frame.

Validation: the focused C test compares the old and new providers, normalizing only their distinct stored return offsets, and tests relocated GetTime refusal, EGA stack rejection, edge overlap and EGA operand-read latch ordering. It passed with `-Wall -Wextra -Wpedantic -Werror` and address/undefined sanitizers. `tools/overlay/res0709_time_0c3f_cpu_audit.py` compares 74 cases against Unicorn executing the original bytes, all 83/83 body and callee instruction starts, CPU14 and all 1 MiB RAM. That differential uses a flat bus, not EGA; EGA-specific behavior is covered by the synthetic C checks. The full CMake build could not link its library because the local temporary filesystem ran out of space; its CTest executables were not run. No native DOSBox-X comparison was performed for this entry.
