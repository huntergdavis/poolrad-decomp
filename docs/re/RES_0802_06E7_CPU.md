## Behaviour

    06E7 PUSH BP; MOV BP,SP
    06EA LES DI,[BP+0Ah]; PUSH ES; PUSH DI; LCALL 0AF8:1491 (Close B); LCALL 0AF8:04A9 (IOCheck)
    06F9 LES DI,[BP+6];   PUSH ES; PUSH DI; LCALL 0AF8:1491 (Close A); LCALL 0AF8:04A9 (IOCheck)

- **The order is B, then A.** From 0716, B is the data FileRec `[BP-0B3h]` and A is the directory FileRec `[BP-133h]`.
- **A close error stops before the second file.** IOCheck's RunError fires at the first non-zero InOutRes, so A is never
  touched after a failure on B.

## Composition and contract

- Both callees are composed from their models on main: Close (`system_close_1491_cpu`, #1309) and IOCheck
  (`system_iocheck_04a9_cpu`, #1306).
- Each far-call segment word is read live from the code, so the loader relocations hold.
- Each callee must return to the instruction after its call; otherwise the stop is **CALLEE**.
- **Declared environment:** Close's INT 21h AH=3Eh service, under Close's own contract.
- Stops:
  - **RUNERROR** (terminal): IOCheck at `0AF8:00E2`, with AX = InOutRes. That is 103 for a file that is not open, or the DOS
    error code.
  - **SERVICE:** the close service declined; CPU at Close's INT.
  - **CALLEE:** a composed model stopped otherwise, or returned elsewhere.
  - **ARGUMENT:** a precondition below failed; nothing is changed.
- Exactly 1 MiB of RAM with the relocated code at CS; IP = 06E7h.
- Entry SP in `[000Ch,FFF4h]`: the pushes reach entry SP − 0Ch inside Close, and the arguments reach entry SP + 0Bh.

**Role line (t30 side i):** closes the two FileRecs of the game's ECL*.DAX archive that 0716 opened through 05CD.
