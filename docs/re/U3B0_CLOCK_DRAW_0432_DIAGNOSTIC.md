# Unit 3B0 clock and label to drawer integration

`pr_u3b0_clock_draw_0432` starts at a caller-supplied live `+0432` prompt frame. It calls the real `0709:0C3F` clock twice, stores the first result at `[BP-57]/[BP-55]`, forms the second result plus 30 and then plus 50 with 16-bit carry into DX, and stores both deadlines. If `[BP-2A]` is nonzero, it pushes the original five printer arguments and calls the real `0709:0626` printer. It then invokes the existing `+047A` drawer/wait/input pipeline. The nested drawer and wait results remain explicit and do not assert that entry2 supplied a result.

Source binding: owner GAME.OVR SHA-256 `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 3B0 file base `2C8CF`, `[0432,047A)` is 72 bytes SHA-256 `d5629387e5abfb0079d488362d2baed6e10301e2010e7d5cd36d551c1b84d660`. Calls are at `+0432`, `+043D`, `+0475`, returning at `+0437`, `+0442`, `+047A`. No game bytes are included.

The caller owns all earlier setup and actual frame, label, list, loaded immutable instructions and live segment relocations, font, bus, EGA and environment services. Entry requires exactly 1 MiB RAM with EGA, IP `0432`, BP `[0090,FFE3]`, SP `[0140,FFFC]`, and ordinary CS/DS/SS windows, in addition to every reached provider's restrictions. The DOS service must obey the clock's no-RAM-write and stable-bus contract. Call sites check the live opcode and offset before their far frames; the segment word is read through the bus after those pushes, so code and call operands must not be overwritten by stack writes. All nested clock, printer, drawer, FIFO and callback restrictions apply. The caller must keep CPU, diagnostic and host structures separate from guest RAM and devices.

An invalid entry is rejected before mutation. A bad call leaves IP at that call, with prior operations and printer argument pushes retained. Each actual callee's non-return preserves its CPU, RAM and EGA effects and exposes its nested diagnostic; unexpected return IP, CS or SP is a transfer stop. The phase identifies the first clock, second clock, printer, or downstream drawer. A reached downstream drawer may itself report an argument, code, callee or transfer stop. There is no arbitrary-PC resume. See [the prior drawer/wait contract](U3B0_DRAW_WAIT_047A_DIAGNOSTIC.md), [clock contract](RES_0709_TIME_0C3F_CPU.md), and [printer contract](RES_0709_PRINTER_0626_CPU.md).
