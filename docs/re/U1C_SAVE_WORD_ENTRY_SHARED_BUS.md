# SAVE operand-word helper entry

`pr_save_word_start` and `pr_save_word_resume` extend the [U25 operand return](U25_OPERAND_RETURN_SHARED_BUS.md) through the SAVE instructions at `+02A0`: read the second operand's high byte, push AX, read its low byte, push AX, and make the far call at `+02A8`. Standalone `pr_u1c_save_word_entry` validates the reached call to stub `+004D`, constructs the real return frame, validates its far jump to U25 `+06AF`, reads the live target segment and stops at the helper entry. It does not execute the helper. The reads and pushes use the shared bus in source order, including aliases that cause the first push to alter the second read. Other earlier outcomes remain distinct.

The [SAVE disassembly and pinned body digest](CANDIDATE_SCOUT_DS41B_BATCH1.md) and [loader audit](U25_LOADER_0000.md) supply the source and helper-entry evidence. GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`; SAVE `[0292,02E0)` is 78 bytes, SHA-256 `7f66f8be811fe835d3ed3ab0fc0772f57e10ab39b5b5beda8aa2542262f92ebb`. No original bytes are embedded.

Standalone entry requires IP `02A0`, SP at least 8, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The caller owns immutable loaded code outside EGA, writes avoiding code, valid binding and reached frames. Malformed call or stub and nonordinary reached segments stop at their actual reached frame after prior source effects. The composed path inherits the prior budgets and profiles; these are bounded assumptions, not a general alias or hardware proof.

Synthetic tests cover the idle-to-Up two-numeric-operand route through the helper frame, malformed call and stub, the stack/data alias between reads, and invalid-entry atomicity. The fixture and wrapper pass strict-warning ASan/UBSan with the provider archive uninstrumented. Native differential, string execution, the helper body and later SAVE effects, movement, visual parity, full gameplay and coverage credit remain unverified.
