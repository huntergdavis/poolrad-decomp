# Unit 0x38 +0x2002: bounded eight-cell selector

`src/recovered/overlay_u38_leaf_2002.c` models the DOS v1.3
`GAME.OVR` U38 `+0x2002..+0x20DE` executable body. The body is
call-free and returns through `RETF 2`. The decoded parent has four
near-call sites, but no natural saved-game frame has been captured.
The game-routine identity and strict full-C count therefore remain
**provisional**.

The pre-implementation `deja "poolrad U38 +2002 221 byte helper +22E7
caller original C parity ownership"` query timed out (exit 124), so it
supplied no reusable claim. The full-RAM CPU comparison and DOSBox-X
wrapped-frame capture were adapted from the reviewed U3B0 +0067 work
at commit `53c87573f3ead2b91ffa2e1590cedbcd60513146`; this leaf's
bytes and assertions were independently checked. That work and U9E
entry0 commit `e75b7615575cfe5897035525843b54e99e50b69e` also
established the Unicorn versus native far-return wrap distinction.

| Item | Measured value |
| --- | --- |
| DOS v1.3 `GAME.OVR` | 206,105 bytes; SHA-256 `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614` |
| Executable body | File `[0x10C5D,0x10D3A)`; unit `[+0x2002,+0x20DF)`; 221 bytes / 75 instructions; SHA-256 `cdf3d522f6de4b8f37ccc47e3267e244f26cab4866883306b9dcfe1525dd2af4` |
| Ledger bound | 288 bytes to next prologue `+0x2122`; 67 trailing bytes after `RETF 2` are not executed by this leaf |
| Entry evidence | Ledger grade B, `helper_candidate`; decoded near calls in U38 `+0x2122` at `+0x22E7`, `+0x2300`, `+0x2313`, `+0x2360` |
| Internal flow | Every decoded branch target remains inside the 221-byte body; no outbound call |
| Exit | `RETF 2` at `+0x20DC` |

The routine scans eight cell bytes at `ES:[DI+0x96]`, using a far
pointer loaded from `SS:[base+8]`. For cell bytes greater than one,
it reads a 32-bit score from a DS table at `0x409B + 0x38*index +
4*cell`; lower cell bytes yield zero. It compares the signed cell
byte with the previously chosen cell, then compares the score as a
signed high word and unsigned low word. The all-ones score receives
special treatment. It stores the selected score and index in the
SS-based caller object and returns the chosen index in AL. The model
preserves instruction-order writes to stack locals and caller fields,
AX/CX/DX/DI/ES effects, final flags, and wrapped far-return SP.

The hash-locked original-byte audit is
`tests/recovered/check_overlay_u38_leaf_2002.py`. Unicorn's far-return
read at `SP=FFFE/FFFF` differs from native 16-bit offset wrapping, so
those frames are checked with the DOSBox-X normal-386 synthetic oracle
`tools/overlay/u38_leaf_2002_native.py`. Its report and generated COM
files remain under ignored `resources/u38-2002-parity/native/`.
