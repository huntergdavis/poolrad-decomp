# Unit 0x38 +0x2002: full-state cell/score selector

This PR brings the unpublished implementation from
[58b2d279eda524341bc7a86d0ae4f86dd9d98dfb](https://github.com/huntergdavis/poolrad-decomp/commit/58b2d279eda524341bc7a86d0ae4f86dd9d98dfb)
onto current main, fixes its LES segment-word addressing, and expands the
original-code evidence. It does not add acceptance or count credit.

The resumed pre-implementation deja query timed out without reusable
results. A follow-up query for DOSBox LES boundary behavior returned no
matches. The inherited audit/native harness originated in that commit;
the actual-RETF and shared A20 backing technique comes from the accepted
U33 +0615 / U25 +0482 audits. The earlier harness attribution to U3B0 +0067
commit 53c87573f3ead2b91ffa2e1590cedbcd60513146 and U9E entry0 commit
e75b7615575cfe5897035525843b54e99e50b69e still applies.

The schema-4 queue's successor export selected this call-free hard body
once higher rows already implemented in main, owned by another author,
or lacking a composable CPU interface were accounted for. In the frozen
schema-6 full-history export it is rank 435 / score 20, penalized for the
unpublished branch. Queue PR #893 subsequently records the reported
U68 +0109 and resident +23DB/+2199 interface caveats. Queue size 105
instructions includes trailing data; the executable body has 75.

The routine reads eight signed cell bytes through the far pointer at
SS:[base+8]. Cells greater than one select a 32-bit DS score at
409B + 38*index + 4*cell (hex constants); other cells produce zero.
Selection compares signed cell tiers, then signed score high words and
unsigned low words, with a special all-ones score. Best/candidate scores
are stored in the inherited frame at offsets -31 through -2A. AL returns
the selected index; when nothing qualifies, it returns the untouched local
byte at entry SS:(SP-3). The original does not initialize that byte.

The C API keeps all 14 CPU words and instruction-order RAM effects. LES
consumes four physically contiguous bytes after 16-bit effective-address
calculation. The imported version incorrectly wrapped the segment word's
16-bit address separately. The new focused regression fails against the
old implementation and passes against this change.

The expanded audit covers every byte value in every cell position, signed
and unsigned score extremes, sentinel/tie paths, every stale selected-index
byte, relocated CS/DS/SS, A20 wrapping, stack endpoints, frame/cell and
score/object aliases, and 128 deterministic randomized RAM cases.

Eight named fixtures exhaust the original 20,000-instruction budget:
frame-0001-0029, frame-0002-0029, frame-0003-0029,
frame-0003-002b, frame-0004-002b, frame-0005-002b,
frame-0005-002d, frame-0006-002d. Their C execution and coverage are
excluded, and the exact exclusion list is asserted. Aliased stores can
rewrite the loop counter; eight iterations are therefore not an API bound.
The C model imposes no artificial limit. These observations do not prove
that every excluded execution is infinite.

The memory profile uses 20-bit A20-wrapped RAM and contiguous scalar/LES
reads, without hardware exceptions or interrupts. Executing-code aliases
are outside the contract. The Unicorn audit executes the actual outer
RETF; its FFFE/FFFF return-frame behavior differs from DOSBox-X normal386,
so those two SP values are checked natively. The C return uses separate
wrapped 16-bit pops, matching those native captures.

Native cases are (SP, base, mode) = (FFFE,9000,0), (FFFF,9000,1),
(FFFB,9000,0), (8000,FFF4,0). Each compares all 14 CPU words and 145
selected RAM bytes: 126 stack bytes, three adjacent physical bytes, eight
score bytes, and eight cell bytes. The capture's PUSHF scratch at
SS:7FFE/7FFF is excluded. Results are 173 bytes each, with COM/result
SHA-256 receipts in the ignored native report. This is not full-RAM native
coverage. LES operands at FFFD..FFFF are covered only by Unicorn. An
exploratory native fixture hit segment-limit faults while setting up the
boundary data; it supplied no successful native LES execution evidence.
