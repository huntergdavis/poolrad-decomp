# Resident 00BA:1073 word-to-string provider

`pr_res_00ba_1073_cpu` models resident `RES_00BA_1073`, the first reached formatter called by `00BA:290B`. It reads the **full unsigned word** at `[BP+6]`, zero-extends it to a long integer, calls the real SYSTEM `1366` decimal formatter into a local 256-byte string, then calls real SYSTEM `0B25` to store that string in the caller's far destination. It ends in `RETF 2`, leaving the destination pointer on the stack. Unlike the neighboring [00BA:1037 byte formatter](SYSTEM_STR_1366_RES_1037.md), values above 255 are not truncated. This provider does not implement `290B`, display output, gameplay, or a coverage credit.

The pinned owner START.EXE SHA-256 is `d825df2b174675c9088ba1489488bdeebe66ad2a22943f17d3a198e60b6a07bd`. Loader-expanded `00BA:[1073,10AD)` is 58 bytes, 27 instructions, SHA-256 `189b8c5536f60fd2c20e4c087348c50648140cce18d772087470e3ec1f11bd4c`. Calls at `+108E` and `+10A2` use live segment words, checked offset/opcode and actual return offsets `+1093/+10A7`. The implementation adapts the established `1037` model, replacing its byte input and instruction offsets; the existing provider is unchanged. Original bytes and game media are not committed.

Entry is after the caller's far call: `[SP]` return IP, `[SP+2]` return CS, `[SP+4]` the word, and `[SP+6]/[SP+8]` destination offset/segment. The bus must expose exactly 1 MiB RAM; IP must be `1073`, SP `[0200,FFF0]`, and CS and SS segment windows must be below `9000` or at least `B000`. Code, call operands and the SYSTEM power table are caller-owned and immutable; all caller and host objects must be distinct from guest memory/device state. The SYSTEM formatter checks the real powers-of-ten table at its live relocated CS. The standard raw leaves reread operands in order and retain their forward-overlap behavior.

With EGA attached, the two leaves use flat RAM. After each actual far frame is pushed, the provider rejects `PROFILE` before the first leaf if the live SYSTEM CS window is not ordinary, or before the second leaf if its live code or destination segment is not ordinary. The first guard preserves the far frame and `1366` entry CPU; the second preserves the completed decimal conversion and `0B25` entry CPU. Initial argument failure leaves CPU, RAM and EGA unchanged; optional diagnostic outputs are reset to no-callee/-1 as in `1037`. A bad call stops at its call site after its source argument pushes; a leaf refusal or return mismatch keeps earlier effects and identifies the last callee/status. The guards are conservative segment-window checks, not proof for arbitrary devices or mutation by external callbacks.

Synthetic checks cover 0, 255, 256, 32768 and 65535, correct Pascal strings and `RETF 2`, an A20-wrapped stack, forward source/destination overlap, each reached call-site failure, altered power-table refusal, EGA SYSTEM/code/destination profile stops and initial atomicity. The new wrapper and focused fixture passed strict warnings and ASan/UBSan. `tools/overlay/res00ba_word_string_1073_audit.py` runs 94 original-byte Unicorn cases: 91 returns, two malformed calls and one power-table refusal, all 27/27 formatter instruction starts, unmasked CPU14 and full 1 MiB RAM. The audit uses a flat bus; EGA guards are synthetic tests. Its `--compile-only` builds/binds the real provider without owner media. No native DOSBox-X or whole-`290B` parity is claimed.
