# OVL_0068 +068D: raw-CPU model of the unit 0x68 Up preflight, through its overlay stub (no new credit)

`OVL_0068_068D` (unit 0x68, internal routine `+068D`, entered by `PUSH CS; CALL +068D` from entry 2's key handler) is
**already strict**. Its credit rests on the path-complete model `overlay_u68_up_preflight.c`
([U68_UP_PREFLIGHT_068D.md](U68_UP_PREFLIGHT_068D.md)). That model merges the translated `pr_u3bd_entry3` and keeps the
two step tables as host state, so it does not take a CPU.

This change adds the **raw-CPU, full-state model** the hybrid executor needs to run the body in place in the live game.
It composes the existing raw model of unit 0x3BD `+0350` (`pr_u3bd_field_0350_fullstate`, which itself runs `+047B` and
`+031F`), **reached through the overlay stub that the model reads from RAM**. It proposes **no credit and no ledger
change**. Assigned by par-a (i21416) as the last body of batch 6.

`deja` recall could not be run (its MCP server fails with ENOENT). The prior work is cited:
- U68_UP_PREFLIGHT_068D.md, for the extent, the frame, the tables and the clamp rule;
- `overlay_u3bd_lookup_fullstate.c` (commit `16bbc747`), for the composed `+0350`;
- `docs/HYBRID_STUB_PRECONDITION_CENSUS.md` and par-e i21377/i21391, for the stub precondition: a body that calls
  another overlay unit must read the stub or fail closed.

## Media and executable extent

- **Media:** START.EXE SHA-256 `d825df2b…a07bd`, GAME.OVR SHA-256 `872964a3…8614`. Both are checked by the audit.
- **Body:** unit 0x68 `[068D,073B)`, **174 bytes / 55 instructions**, at GAME.OVR file offset 93,528. SHA-256
  `54bf1c34b310e1645d1b7c855a1fc17630282901b9fa64fb01b7ee7e33ca34aa`, the same span hash the credit doc records. It ends
  in its only return, `RETF` at `073A`.
- **Callee:** unit 0x3BD's whole code image (SHA-256 `2473c8de…fdd0a`) is placed in the audit, so the original really runs
  `+0350`, `+047B` and `+031F`.
- **Checked by the audit's source step:**
  - the one far call is `LCALL 03D5:002F` at `06C0`;
  - **the only relocation in the span is that LCALL's segment word at `06C3`**;
  - unit 0x3BD public entry 3 is `+0350`;
  - there is no near call, interrupt or port instruction in the body.

## What the body does

The frame after the far call is `[SP]` IP, `[SP+2]` CS. The body takes no arguments.

1. **Enter.** `PUSH BP; MOV BP,SP; SUB SP,6`.
2. **Locals.**
   - `[BP-2]` is x, from `CBW` of `DS:[6AAD]`.
   - `[BP-4]` is y, from `CBW` of `DS:[6AAE]`.
   - `[BP-6]` is the facing: `DS:[6AAF]` with `XOR AH,AH`, so 0..255.
3. **Clear the window word.** `LES DI,[49D6]; XOR AX,AX; MOV ES:[DI+5AA],AX`.
4. **The lookup.** It pushes x, y and the facing as low bytes, then `LCALL 03D5:002F`. That is the stub of unit 0x3BD
   entry 3 (`+0350`), which ends `RETF 6`.
5. **Gate.** `OR AL,AL; JE 0737`. A zero result skips everything below.
6. **Step.**
   - `[BP-2] += CBW DS:[2736+f]`.
   - `[BP-4] += CBW DS:[273F+f]`.
   - The two tables are 9 bytes apart, so a facing above 8 reads into the other table.
7. **Clamp.** These are four signed compares, each rereading its local:
   - x above 15 stores 0Fh to `[6AAD]`;
   - x below 0 stores 00h to `[6AAD]`;
   - y above 15 stores 0Fh to `[6AAE]`;
   - y below 0 stores 00h to `[6AAE]`.

   Each clamp re-reads `LES DI,[49D6]` and sets `ES:[DI+5AA]` to 1. **The candidate is never stored when it stays in
   range.**
8. **Leave.** `MOV SP,BP; POP BP; RETF`.

**Flags at return** are those of the last flag-setting instruction:
- **the clamp path:** the last `CMP`;
- **the zero path:** `OR AL,AL`.

`+0350`'s shift leaves AF wrong in the composed full-state model (i21438). **That flag is overwritten by `OR AL,AL`
before anything in this body reads or returns it.** The 253 equal Unicorn cases, compared with no flag mask, pin this.

## Role

**The Up-key preflight of the exploration input loop** (U68_UP_PREFLIGHT_068D.md). It moves the party one step in the
facing direction only as far as the 0..15 grid allows. It raises the window-1 word `5AAh` when it clamps. Further game
meaning is not asserted.

## The stub precondition

The LCALL's target is **read, not assumed**:
- the offset word comes from `CS:06C1`, and the relocated segment word from `CS:06C3`;
- the stub's five bytes must be `EAh`, offset `0350h`, segment S;
- `pr_u3bd_field_0350_fullstate` then runs at `S:0350`.

**Anything else stops OVERLAY with the CPU at the stub**, with the far return frame and the three arguments pushed. That
is exactly where the original enters the overlay manager. An unloaded stub holds `INT 3Fh`.

This is the fail-closed form par-e asked for, and it also covers a loaded far JMP to another offset. The hybrid glue
treats OVERLAY as "decline, run the original".

## Raw contract and stops

`pr_u68_up_preflight_068d_cpu(bus, size, cpu)`:
- exactly 1 MiB of A20-off RAM behind a `pr_bus`;
- IP `068Dh`;
- **entry SP in [0030h, FFFCh]**.

**Why the SP floor is 0030h.** The composed chain (`+0350`, then `+047B`, then `+031F`) writes **30h bytes below the
entry SP**, the deepest point measured over the quick case set. An entry SP of 002Ah wrapped the stack inside the segment.
The original then ran away in Unicorn, which places a word that straddles FFFFh contiguously. The floor keeps every frame
inside the segment.

| Stop | Class | Origin | Pinned by |
| --- | --- | --- | --- |
| RETURNED | RETURN | `RETF` to the entry frame's return address | Unicorn: 226 of 253 cases; native: 32 of 32 |
| OVERLAY | precondition | the stub is not a loaded far JMP to `+0350` | Unicorn: 26 cases (an `INT 3Fh` stub stops both sides at the stub); C test: unloaded, and loaded to `+047B` |
| TRANSFER | control transfer | `+0350`'s `RETF 6`, or this body's `RETF`, popped another return address | Unicorn: 1 case, `window-on-ret-cs`. The raised window word is placed on the return CS, so the original leaves for segment 1 and so does the C |
| CALLEE | callee | the composed `+0350` model rejected its entry | not reached: the entry checks above imply `+0350`'s. Kept as a guard |
| ARGUMENT | ARGUMENT | null bus/RAM/CPU, size, IP, or entry SP outside [0030,FFFC] | C test (ASan/UBSan): CPU and RAM untouched |

| Pointer | Source | The body's own access | Bus? |
| --- | --- | --- | --- |
| the window far pointer `DS:[49D6]`/`[49D8]` | a DS global | read by `LES` up to five times; **the pointee word `ES:[DI+5AAh]` is written** (cleared, then 1 per clamp) | words: no; **the stores: yes, through the bus, low byte first** |

**What pins the bus claim.** Unicorn has no planar EGA, so the "window stores bypass the bus" mutant survives the
differential, as expected. **It is caught by the C test**: with the window at `A000:0000`, the word at `A000:05AA` reaches
plane 0 and RAM is left alone.

## Checks

The audit is `tools/overlay/ovl_0068_068d_cpu_audit.py` (`CHECKER_ROWS = ('OVL_0068_068D',)`). The original bytes of the
body and of unit 0x3BD run in Unicorn; the C runs on the same state. The comparison covers **CPU14 and all 1,048,576 RAM
bytes, with no flag mask**.

**Unicorn: 253 cases, every one equal.**

- **Coverage:** 55 of 55 body instruction starts and **10 of 10 conditional outcomes**.
- **End states:** 226 RETURNED, 26 OVERLAY, 1 TRANSFER.
- **Grid:** every clamp edge, corners and in-range moves, on three buffer fills (so `+0350` returns 1 or 3).
- **The zero result:** out of the grid on maps 0 and 0Ah.
- **Signed values:** facings 0..8 and FFh (the overlapping tables), and x of 7Fh, 80h, FFh and 10h.
- **Machine state:** four incoming-flag values, entry SP edges, and the window pointer wrapping at 16 bits and at A20.
- **Aliasing:**
  - DS = SS;
  - **the window word on `[BP]`, on each local and on the return CS;**
  - `window-on-x-negative`, where the raised word rewrites the x local between the two x compares.
- **Stubs:** two unloaded-stub cases and 200 random cases, with 10% of the random stubs unloaded.

**Independent statements.** 221 cases are also checked without the C model:
- the party bytes and the window word, from the clamp rule given the `+0350` result the original produced at `06C5`;
- SP, BP and CS:IP on return.

They are skipped where the window word aliases the party bytes or the frame.

**Mutants: 9, all caught,** 8 by the differential and 1 (the bus bypass) by the C test.

| Mutant | Result |
| --- | --- |
| the stub is not read (assumed loaded) | caught (`unloaded-stub`) |
| the dy table is at 2737 | caught |
| the clamp writes 0Eh | caught |
| unsigned clamp compare | caught, **only by `window-on-x-negative`**. Without aliasing, a negative x fires both clamps and the second one wins, which is the same result |
| the window flag is not raised on the x upper clamp | caught |
| the window word is not cleared first | caught |
| the facing is sign-extended | caught |
| RETF pops 2 argument bytes | caught |
| the window stores bypass the bus | caught by the C test |

**C test:** `tests/recovered/test_overlay_u68_up_preflight_068d_cpu.c`, run under ASan/UBSan. It covers:
- the in-range move;
- each of the four clamps;
- the signed x of 80h;
- the return flags;
- the zero result on maps 0 and 0Ah;
- the unloaded stub: OVERLAY at the stub with the frame and arguments checked;
- a loaded JMP to another offset;
- the bus store with an EGA;
- atomic argument rejection.

**Native:** `tools/overlay/ovl_0068_068d_native.py`, DOSBox-X normal/386 (the host's packaged build), with no masks. The
original body and unit 0x3BD run under a real DOS through a loaded `EAh` stub.

**32 of 32 cases pass**, comparing 10,486,656 bytes (DOSBox-X sha256 `99d74601…0df3`):
- the in-range move and eight clamp pairs, including x = 80h and 7Fh;
- the zero result on maps 0 and 0Ah, and map 1;
- facings 0, 1, 7, 8 and FFh;
- five incoming-flag values, with IF cleared;
- SP at the floor, at the top, and odd;
- the window pointer wrapping at 16 bits, and DS = SS;
- the raised window word on `[BP]`, on each local, and `window-on-x-negative`.

## What this does not show

- **No credit and no identity claim.**
- **OVERLAY is not run natively.** The real `INT 3Fh` vector is DOS's own. Unicorn and the C test pin it.
- **CALLEE is unreached by construction**; it is kept as a guard.
- **The composed `+0350` carries the AF defect of i21438 inside its own frame.** This body overwrites the flag. The
  `+0350`/`+047B` bodies themselves stay held from the hybrid until the fix lands.
- **Not yet glued into the hybrid.**
