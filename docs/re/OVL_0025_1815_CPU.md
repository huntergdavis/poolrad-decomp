## Executable extent

GAME.OVR unit 0x25 **[1815,18EB), 214 bytes / 86 instructions**, `RETF 8` at 18E8. Nine far calls to SYSTEM:
- StrStore `0AF8:0B25` at 182B and 183F;
- FillChar `0AF8:16A8` at 1850;
- the string compare `0AF8:0C10` at 1861, 1879, 1891, 18A9, 18C1 and 18D9.

Their nine segment words (fixups 182E..18DC) are the unit's only relocations in the span.

## What the body does

Arguments: the string a at `[BP+0Ah]` (pushed first) and b at `[BP+6]`, both far pointers to Pascal strings.

1. `PUSH BP; MOV BP,SP; SUB SP,200h`.
2. StrStore a (at most FFh bytes) to the local `[BP-100h]`, and b to `[BP-200h]`.
3. FillChar six zero bytes at `DS:[6F78]`.
4. Six compares of (a, b), each setting one byte to 1 when its Jcc is not taken:
   - `[6F78]` a = b (JNE skips); `[6F79]` a <> b (JE);
   - `[6F7A]` a < b (JAE); `[6F7B]` a > b (JBE);
   - `[6F7C]` a <= b (JA); `[6F7D]` a >= b (JB).
5. `MOV SP,BP; POP BP; RETF 8`.

The copies come before the clear, so a string over the flag bytes is compared as it was on entry.

## Raw contract and stops

`pr_u25_compare_strings_1815_cpu(ram, size, cpu, budget)`:
- exactly 1 MiB of A20-off RAM, **flat**. The body only pushes the string pointers; the callees read them flat, like every flat SYSTEM string leaf;
- IP 1815; entry SP in `[0220h,FFF4h]`, so the 512-byte locals, the callees' frames and the `RETF 8` frame stay in the stack segment;
- **each instruction of this body costs one unit of `*budget`**; the SYSTEM callees do not (they are bounded);
- each LCALL's opcode and offset word are checked (**CODE**, at the call, before its frame); its segment word is read from the code;
- the callees are the raw models `pr_system_strstore_0b25`, `pr_system_fillchar_16a8` and `pr_system_strcmp_0c10`.

The flags at RETURNED are the last string compare's (`SUB SP,200h` is this body's only flag writer).

| Stop | Pinned by |
| --- | --- |
| RETURNED | Unicorn and native |
| LIMIT | Unicorn: the budget sweep, with equal state and budget at the same unexecuted instruction; C test |
| CODE | C test: a changed offset word at a call site |
| TRANSFER | Unicorn: with SS = DS and SP at 6F78h or 6F7Ah, FillChar's six zero bytes land on this body's return address, so RETF 8 goes elsewhere in both runs |
| ARGUMENT | C test: null RAM, CPU or budget; short RAM; IP; SP. CPU and RAM untouched |
