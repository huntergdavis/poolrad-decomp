# Fourth SAVE dispatcher return

`pr_fourth_dispatch_return_start` and `pr_fourth_dispatch_return_resume` extend the [fourth SAVE handler return](U1C_FOURTH_HANDLER_RETURN_SHARED_BUS.md) through the existing [dispatcher return](U1C_SAVE_DISPATCH_RETURN_SHARED_BUS.md). The helper reads the live frame on the shared bus and performs the checked return to runner `+31A8`; its expected target is derived and copied from the outer frame at start. Earlier fourth-store and other outcomes pass through unchanged. A mismatched live return stops after executed effects. This composition reuses [third SAVE dispatcher return](U1C_THIRD_DISPATCH_RETURN_SHARED_BUS.md).

Start rejects outer BP below 56 or any nonempty nested handler, store-return, low, dispatch, classifier-return, classifier, store, value, pair-return, pair, slot, branch, loader, SAVE, dispatcher or runner before mutation. It inherits earlier frame, budget, code and caller requirements. These are bounded assumptions, not a general alias or hardware proof. No original bytes are embedded.

Synthetic integration covers the idle-to-Up fourth low no-op route through the checked runner return, copied target, a fourth later opcode, an earlier third operand-string stop, and atomic rejection and retry for each nested phase and invalid BP. Existing standalone tests cover mismatched returns; fourth-route writes and most earlier stop mappings are not separately driven here. The wrapper and fixture pass strict-warning ASan/UBSan with the provider archive uninstrumented. No native differential, runner continuation, movement, visual parity, full gameplay or coverage credit is claimed.
