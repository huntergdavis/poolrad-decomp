# Resident RES_00BA_26C2 and unit 0x86 +0729: raw-CPU full state

This PR adds two raw-CPU, full-state models, both approved by the VP on
2026-10-17. Each takes the queue's sole-blocker role: an uncredited routine
that alone blocks other overlay bodies. The recall attempt for this lane
found nothing to reuse, and schema 7 shows no inline coverage, model or
branch for either.

- **`pr_res_00ba_26c2_cpu`** models the complete START.EXE resident routine
  `RES_00BA_26C2`. It has no prior model, and the callable ledger lists 18
  overlay callers. Its identity is unresolved, so credit is the verifying
  lane's call, the same rule as for `RES_00BA_2199`. The model is useful
  either way.
- **`pr_u86_entry3_0729`** models GAME.OVR unit `0x86` public entry 3
  (`+0729`), which `RES_00BA_26C2` alone blocked. It calls the resident
  routine as a real far call.

## Complete ABIs and ordered effects

Both are entered after the far CALL with `SS:[SP]` return IP, `[SP+2]`
return CS and `[SP+4]` a word whose low byte k is the argument, and both
return with `RETF 2`. T is the 16-byte DS table entry at `31FA + 16k`.

**`RES_00BA_26C2`.**

1. `PUSH BP; MOV BP,SP; SUB SP,2`. Then DI := 16k and CL := 4, and the
   routine compares c = T[0] with 0, 1 and 2.
2. The result byte `[BP-1]` depends on c:
   - c = 0: byte `+96h` of the far pointer `DS:5D92`, which ES:DI then
     holds;
   - c = 1: byte `+9Bh` of the same record;
   - c = 2: 0Ch;
   - anything else: the stack byte already at `[BP-1]`.
3. If `DS:6DBF` is nonzero, DI := 16k again, and unless T[0] is 2,
   `[BP-1]` := 6.
4. AL := `[BP-1]` and AH = 0.

The final flags are those of `CMP [6DBF],0` when that byte is 0, and
otherwise of `CMP [DI+31FA],2`.

**U86 `+0729`.**

1. `PUSH BP; MOV BP,SP; SUB SP,2`.
2. The result byte `[BP-2]` depends on `DS:6DBF`:
   - **0:** `PUSH` k, and `RES_00BA_26C2` returns r. `[BP-2]` := the low
     byte of T[3]·r + T[2], from `MUL DX` and `ADD`. DX then holds the
     product's low word.
   - **Nonzero:** `[BP-2]` := the low byte of 6·T[3] + T[2], with SI :=
     2·T[3] and DX := T[2].
3. If `[BP-2]` is 0 and T[6] is nonzero, `[BP-2]` := 1. If it is FFh, it
   becomes 1.
4. `[BP-1]` := `[BP-2]` and AL := `[BP-1]`.

The final flags are those of `CMP [BP-2],FFh`. The far call is read from RAM
(`9A C2 26` plus a segment). It pushes CS and the next IP, relative to the
entry IP, then runs the resident model at that segment, which must return
there. Otherwise the result is `CODE` or `TRANSFER`.

**Flags.** Both models fold their `XOR`, `SHL DI,CL`, `MUL`, `SHL` and
`ADD` flag writes, which a later `CMP` overwrites before any read. `XOR`'s
AF and `SHL`'s AF and OF are undefined there, and both oracles agree on
the final states.

Every operand is reread from RAM in source order. Offsets wrap at 16 bits
and physical addresses at 1 MiB. `LES` pairs and the `RETF` frame are read
physically contiguous. Null RAM/CPU, or RAM that is not exactly 1 MiB, is
rejected before mutation.

## Validation and parity review

**Focused C test.** `test_res26c2_u86_0729.c` runs under CTest with
ASan/UBSan, and compiles with `-Wconversion -Werror`. It passes 55 checks:

- every class with the `DS:6DBF` override off and on, with exact AL, ES:DI,
  CL, flags and frame;
- both `+0729` paths, with exact AX, DX, SI, flags, the pushed argument
  word and the return frame;
- the 0 and FFh fix-ups;
- `CODE` at a rewritten site;
- the argument guards.

**Unicorn differential.** `tools/overlay/res26c2_u86_0729_audit.py` places
the expanded START.EXE image at load segment 0, so `RES_00BA_26C2` runs from
its original bytes whether called directly or from `+0729`'s unrelocated
far call. It loads unit 0x86 and compares the entire 1 MiB RAM and all 14
CPU words with no mask:

| Body | Returning cases | Instruction starts | Conditional outcomes |
| --- | --- | --- | --- |
| `RES_00BA_26C2` | 363 | 38/38 | 10/10 |
| U86 `+0729` | 403 | 69/69 | 8/8 |

The cases cover:

- all 256 arguments, with classes 0 to 3 and FFh and the flag off and on;
- 96 random worlds of tables, records, registers and FLAGS;
- forty `+0729` worlds aimed at the 0 and FFh fix-ups;
- eight segment-end stacks and SS across A20;
- a random background and preserved DF/IF.

**DOSBox-X oracle.** The normal-core/386 synthetic oracle passes **160
cases**, 80 per routine. Each case compares all 14 CPU words, 64 stack
bytes and the 19 bytes it wrote, with no mask. The COM copies unit 0x86 to
paragraph `8800` and the 103 resident bytes to `9000:26C2`. It relocates
`+0729`'s fixup-backed segment word to `9000`, loader-style. The result
SHA-256 is `3d778eba3f1bb20a7da2111c0932781bf460a39ea1c106681c10541ecef684cc`
with COM segment `0814`. Original bytes and generated images stay under
ignored `resources/`.
