# Unit 1C script runner through first dispatch

`pr_u1c_runner_start` and `pr_u1c_runner_resume` extend the [script-entry path](U1C_UP_SCRIPT_ENTRY.md) on the same bus and CPU through the first `+3171` runner iteration. Standalone `pr_u1c_runner_prefix` begins at `+3171`: it pushes BP, reads the live argument, writes `DS:49ED`, clears and rereads `DS:442E`, and reads `DS:49FF` where reached. A nonzero stop gate follows the real epilogue and checks the live `RETF 2` result against a caller-supplied target. Otherwise it moves the live previous opcode, reloads the PC and script pointer, performs the source 16-bit addition, reads the opcode through the shared bus, stores the latch, validates the reached near call at `+31A5`, pushes its real return frame and stops at dispatcher `+2F2D`. No dispatcher or handler effects are fabricated. Earlier prompt-loop and alternate-dispatch boundaries remain distinct terminal outcomes.

Pinned GAME.OVR SHA-256 is `872964a32cef0fc32bbf83bab68b15e04ad36d59076f37b00a179dfee7928614`, unit 1C file base `0D46`. Runner `[3171,31B3)` is 66 bytes, SHA-256 `4055cdf54a816923efbebe1bed325b67193264be3f6c20491f4f383d692aa489`. The earlier [3171 audit](U1C_ECL_RUN_3171.md) and existing `pr_u1c_run_3171` supplied prior evidence; the runner was independently decoded against the pinned overlay. This wrapper stops on the first reached dispatcher entry or early runner return and does not implement the runner loop after dispatch. No original bytes are embedded.

Standalone entry requires IP `3171`, `SP` in `[0006,FFFA]`, exactly 1 MiB RAM, EGA attached, and ordinary CS/DS/SS windows below `9000` or at least `B000`. The composed session requires a 1C caller BP of at least 14 to keep this frame in profile and inherits the earlier U68, 1C and provider requirements. The caller owns real code and bindings, immutable code outside EGA, writes that avoid code and nonwrapping reached return frames. Opcode reads use the shared bus, including EGA latches and 16-bit offset wrapping. A malformed near call stops at `+31A5` after the source CS push, preserving the fetched opcode and arithmetic flags. This is a bounded profile, not a general alias or hardware proof.

Synthetic tests cover idle-to-Up through display and first dispatcher frame, live opcode and previous-latch updates, EGA opcode reads and latches, wrapped ADD flags, malformed call, stack aliases affecting the stop gate and saved BP, checked immediate return and unexpected transfer, copied target, suspended CPU tampering and invalid-frame atomicity. The wrapper and fixture passed strict-warning ASan/UBSan linked against the existing provider archive. The dispatcher and handlers, subsequent runner iterations, original-runtime or native differential, later movement, visual parity, full gameplay and coverage credit remain unverified.
